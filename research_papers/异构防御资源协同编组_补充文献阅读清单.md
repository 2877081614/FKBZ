## 1. 补文献目标

当前已有文献已经覆盖 MADDPG、QMIX、MAPPO、Gumbel-Softmax、RND、MAAC、GAT、Qatten、WTA 和 MAGNNET 等基础。但如果小论文方向确定为“异构防御资源协同编组”，还需要补齐三类支撑：

1. 异构 MARL：证明不同类型防御资源不应简单当作同质 agent 处理。
2. 异构任务分配：支撑“资源-目标匹配”“动态任务分配”“规则基线/WTA/CBBA/Hungarian”等问题建模。
3. 反无人机资源协同：支撑 Sensor/Jammer/Interceptor 等资源抽象的领域合理性。

建议优先读 12 篇，其中 P0 为必须精读，P1 为支撑实验和相关工作，P2 为背景和场景建模补充。

## 3. P0 必读文献

### P0-1. Trust Region Policy Optimisation in Multi-Agent Reinforcement Learning

链接：https://arxiv.org/abs/2109.11251

类别：异构 MARL / HATRPO / HAPPO。

为什么必须读：

这篇是异构 agent 策略优化的关键文献。它提出 HATRPO 和 HAPPO，不要求 agent 参数共享，也不要求联合价值函数满足严格可分解假设。你的防御资源包括 Sensor、Jammer、Interceptor，本质上就是异构 agent。若直接使用参数共享 MAPPO，审稿人可能会质疑不同资源类型被过度同质化。

阅读重点：

- Multi-agent advantage decomposition lemma。
- Sequential policy update。
- HATRPO/HAPPO 为什么适合 heterogeneous agents。
- 它与 MAPPO、MADDPG 的差异。

如何用于论文：

- 在相关工作中说明：传统 MAPPO 常用于合作 MARL，但异构资源场景中，不同 agent 的观测、动作和能力不同，因此需要类型感知策略或异构 agent 策略结构。
- 在方法中可以借鉴 HAPPO 的思想，设计 Resource-Aware MAPPO 或不同资源类型 actor。

### P0-2. Heterogeneous-Agent Reinforcement Learning

链接：https://arxiv.org/abs/2304.09870

类别：异构 MARL 总框架。

为什么必须读：

这篇比 P0-1 更像异构 MARL 的体系化总结。它提出 HARL 框架，并讨论 HATRL、HATRPO、HAPPO、HAA2C、HADDPG、HATD3 等算法。对你而言，它可以作为“异构资源协同编组为什么需要异构 MARL”的主要理论支撑。

阅读重点：

- HARL 对 homogeneous-agent parameter sharing 的批评。
- HAML 框架。
- HADDPG/HATD3 与传统 MADDPG/TD3 的关系。
- 实验中如何比较异构算法与 MAPPO/QMIX。

如何用于论文：

- 如果你选择 MAPPO 主干，可引用该文支撑“资源类型 embedding + 非完全共享策略”。
- 如果你选择 MADDPG 主干，可引用 HADDPG 思路。

### P0-3. MAGNNET: Multi-Agent Graph Neural Network-based Efficient Task Allocation for Autonomous Vehicles with Deep Reinforcement Learning

链接：https://arxiv.org/abs/2502.02311

类别：异构任务分配 / GNN / MARL。

为什么必须读：

这是当前最贴近你方向的文献之一。它针对异构多智能体系统中的动态任务分配，将 GNN、CTDE 和 PPO 结合起来，并与 Hungarian、greedy 等基线比较。虽然场景不是反无人机，但“异构 agent + 动态任务 + 分配冲突 + 去中心化执行”与你的小论文高度相似。

阅读重点：

- 如何把 agent 和 task 建成图。
- 如何定义任务分配动作。
- 如何处理 assignment conflict。
- 如何与 Hungarian 和 greedy baseline 对比。
- 它的评价指标：成功率、冲突率、任务耗时、扩展性。

如何用于论文：

- 作为你方法设计的直接参考。
- 支撑“资源-目标二部图”或“资源类型感知任务分配”的建模。
- 支撑实验中加入 Hungarian 和 greedy 基线。

### P0-4. A Decentralized Multi-UAV Spatio-Temporal Multi-Task Allocation Approach for Perimeter Defense

链接：https://arxiv.org/abs/2102.07381

类别：防御任务分配 / perimeter defense。

为什么必须读：

这篇非常适合支撑“保护目标/保护区域 + 入侵者 + 防御者”的问题结构。它把入侵者到达边界的时间和位置看成 spatio-temporal task，用去中心化多 UAV 任务分配解决 perimeter defense。你的反无人机动态编组也可以把来袭 UAV 看作带时间约束的威胁任务。

阅读重点：

- Perimeter defense 的问题定义。
- Intruder 如何转化为空间-时间任务。
- 防御者如何分配任务。
- Monte-Carlo 场景和评价指标。

如何用于论文：

- 支撑你将 UAV 威胁定义为动态任务。
- 可借鉴“预计突防点/突防时间”的威胁特征。
- 可作为非学习型分配基线或场景构建参考。

### P0-5. Counter-Unmanned Aircraft System(s) (C-UAS): State of the Art, Challenges and Future Trends

链接：https://arxiv.org/abs/2008.12461

类别：反无人机综述。

为什么必须读：

这篇可支撑反无人机场景中的资源抽象。它总结 C-UAS 的 detection、tracking、identification、mitigation 链条，也讨论 acoustic、vision、RF、radar、fusion 以及 jamming、capture 等处置方式。你不做 CV，但可以用它说明为什么防御资源应分为探测、跟踪、压制、拦截等类型。

阅读重点：

- C-UAS 系统功能链：detect-track-identify-mitigate。
- 主要传感器和处置手段分类。
- C-UAS 挑战：小目标、低空、蜂群、误警、法规约束。
- Mitigation 技术分类：jamming、capture、hard kill 等。

如何用于论文：

- 引言中支撑反无人机威胁和异构资源必要性。
- 方法中支撑 Sensor/Jammer/Interceptor 三类资源抽象。

### P0-6. Partial Replanning for Decentralized Dynamic Task Allocation

链接：https://arxiv.org/abs/1806.04836

类别：动态任务分配 / CBBA 扩展。

为什么必须读：

反无人机任务是动态到达的：新目标可能随时出现，已有目标威胁等级会变化，资源也会消耗或冷却。CBBA-PR 关注在线新任务出现时如何局部重规划，而不是完全重新分配。这对你设计“动态编组切换代价”和规则基线很有帮助。

阅读重点：

- CBBA-PR 如何在已有分配上做部分重规划。
- 它如何权衡收敛时间和任务质量。
- 通信负担如何降低。
- 多 UAV 仿真实验如何设置。

如何用于论文：

- 作为动态任务分配相关工作。
- 作为规则基线设计参考。
- 支撑“频繁重编组有代价，需要控制切换”的动机。

## 4. P1 支撑文献

### P1-7. A Formal Analysis and Taxonomy of Task Allocation in Multi-Robot Systems

链接：https://doi.org/10.1177/0278364904045564

类别：多机器人任务分配基础。

为什么读：

这是 MRTA 经典分类文献。它能帮助你把“异构防御资源协同编组”放入多机器人任务分配的学术谱系中，避免相关工作只写 MARL 而缺少任务分配基础。

阅读重点：

- Single-task robot / multi-task robot。
- Single-robot task / multi-robot task。
- Instantaneous assignment / time-extended assignment。
- 你的问题属于哪一类。

如何用于论文：

- 在问题定义中说明你的任务是动态、时间扩展、异构能力约束下的多资源任务分配。

### P1-8. Consensus-Based Decentralized Auctions for Robust Task Allocation

链接：https://doi.org/10.1109/TRO.2009.2022423

类别：CBBA / 去中心化拍卖分配。

为什么读：

CBBA 是多 UAV / 多机器人任务分配中非常常用的经典基线。你的小论文如果只和 MARL 比，可能不够稳；加入 greedy、Hungarian、CBBA 类基线，会让实验更像任务分配论文。

阅读重点：

- Bundle construction。
- Consensus phase。
- Conflict-free assignment。
- 去中心化分配和通信需求。

如何用于论文：

- 作为规则基线或相关工作。
- 对比 RL 方法与传统分布式任务分配方法的差异：传统方法收敛快、可解释；RL 方法适合复杂动态奖励和资源效果耦合。

### P1-9. Deep Decentralized Multi-task Multi-Agent Reinforcement Learning under Partial Observability

链接：https://proceedings.mlr.press/v70/omidshafiei17a.html

类别：多任务 MARL / 部分可观测。

为什么读：

你的场景天然部分可观测：每类资源只能看到局部目标、资源状态和通信信息。该文可以支撑“去中心化执行 + 多任务 + 部分可观测”的设定。

阅读重点：

- Decentralized multi-task MARL 的问题表述。
- Partial observability 下如何训练。
- 多任务之间如何共享表示或经验。

如何用于论文：

- 用于相关工作中补足“部分可观测多任务 MARL”背景。
- 如果你后续加入通信受限或局部观测，可作为理论支撑。

### P1-10. Multi-Target Pursuit by a Decentralized Heterogeneous UAV Swarm using Deep Multi-Agent Reinforcement Learning

链接：https://arxiv.org/abs/2303.01799

类别：异构 UAV MARL / 多目标追踪。

为什么读：

这篇已经在你现有方向论文中出现，但建议提升阅读优先级。它不是反无人机资源分配，但包含异构角色、探索/跟踪、多目标追踪等思想，可为 Sensor/Jammer/Interceptor 分工提供类比。

阅读重点：

- 异构 UAV swarm 如何定义角色。
- 探索与跟踪如何平衡。
- Voronoi-based rewarding policy。
- 真实 Crazyflie 验证部分如何增强可信度。

如何用于论文：

- 支撑“异构角色/资源类型”在 UAV swarm 任务中的有效性。
- 可借鉴角色化 reward 或探索-处置平衡机制。

## 5. P2 背景补充文献

### P2-11. A Survey on Detection, Tracking, and Classification of Aerial Threats using Radars and Communications Systems

链接：https://arxiv.org/abs/2211.10038

类别：反无人机感知背景。

为什么读：

虽然你不做 CV，但 Sensor 资源不能凭空出现。这篇综述讨论 radar、communication-radar、passive signal monitoring 等非 CV 方式，可支撑你把 Sensor 抽象为雷达/RF/通信感知资源。

阅读重点：

- Radar/JCR/passive communication signals 的探测功能。
- UAV 和 manned aircraft 的检测差异。
- 小型 UAV、低空、蜂群造成的困难。

如何用于论文：

- 支撑 Sensor 类型不是图像检测，而是雷达/RF/通信探测抽象。

### P2-12. An Autonomous Drone System with Jamming and Relative Positioning Capabilities

链接：https://arxiv.org/abs/2206.04307

类别：反无人机干扰系统。

为什么读：

这篇能支撑 Jammer 资源的现实动机。它讨论一个具备干扰和相对定位能力的 autonomous counter-drone system，并包含 field experiments。对你来说，重点不是复现硬件，而是借鉴“jamming 作为一种可建模防御资源”的作用机制。

阅读重点：

- Jamming 和 spectrum sweeping 如何结合。
- GPS disruption / wireless interception 的任务逻辑。
- Field experiment 中如何评价干扰效果。

如何用于论文：

- 支撑 Jammer 资源建模。
- 可将 jammer 效果简化为降低目标速度、降低导航能力、增加突防失败概率或延长到达时间。

## 8. 对当前研究设计的启发

基于这 12 篇文献，你的小论文创新点可以更稳地表述为：

> 现有 MARL 方法多面向同质合作智能体，传统 MRTA 方法虽能处理任务分配但难以表达异构资源间的连续协同效应。本文面向反无人机动态防御，构建包含探测、压制和拦截资源的异构任务分配环境，并提出资源类型感知的 MARL 方法，在动态威胁、资源消耗和任务重分配条件下提升防御成功率并降低资源浪费。

这个表述把三条文献线都接起来了：

- 异构 MARL：为什么需要资源类型感知策略。
- 异构任务分配：为什么是动态资源-目标分配问题。
- 反无人机资源协同：为什么要有 Sensor/Jammer/Interceptor。
