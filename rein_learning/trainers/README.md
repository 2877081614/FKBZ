# Trainers

Training and evaluation orchestration belongs here.

Examples:

- `train_tabular.py`
- `train_sb3.py`
- `train_rllib.py`
- `evaluate_policy.py`

Trainers wire together environments, agents, algorithms, buffers, models, configs, and logging.
