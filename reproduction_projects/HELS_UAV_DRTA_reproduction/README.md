# HELS-UAV-DRTA Reproduction Archive

This folder contains the HELS-UAV-DRTA paper reproduction assets only.

It is kept as a reference project for learning, reproduction practice, and background exploration. It should not be treated as the main research output direction or as a primary benchmark for future topic selection.

## Contents

- `HELS_UAV_DRTA/`: reproduction code, environment, algorithms, verification scripts, and local experiment outputs.
- `MADDPG-IA_reader/`: extracted paper reading notes and assets.
- `MADDPG-IA_paper.pdf`: source paper used for the reproduction.
- `MADDPG-IA_复现流程文档.md`: reproduction process notes.
- `说明文档.md`: earlier topic and reproduction notes.
- `checkpoints/`, `logs/`, `runs/`, `figures/`: generated experiment artifacts from the reproduction.

## Project Role

Use this archive as:

- a reference implementation study,
- a record of prior reproduction work,
- a source of engineering lessons for MARL simulation.

Do not use it as:

- the final academic direction,
- the main quality benchmark,
- the main comparison target for future research planning.
