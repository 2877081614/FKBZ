# AirDefense v1.0 任务九自回归动作机制筛选实验

更新时间：2026-07-17  
阶段状态：工程实现与 30k 筛选完成，100k 正式实验暂缓  
结果目录：`results/air_defense_v1/task9_autoregressive_screening_30k_3seeds/`

## 1. 研究问题

任务九检验固定顺序的条件联合动作生成能否同时实现：

- 非法动作、分配冲突和过度分配严格为 0；
- 恢复任务八联合枚举方法损失的资源效率；
- 保持奖励和毁伤性能；
- 在异质性压力下稳定降低高威胁目标突防。

环境、奖励、观测、共享 MLP 和 PPO 核心超参数全部冻结。

## 2. 实验协议

```text
训练场景：medium
测试场景：medium / time_pressure / heterogeneity_pressure
规则方法：greedy_damage / hungarian_damage
学习方法：maskable_ppo / conflict_free_maskable_ppo /
          autoregressive_maskable_ppo
训练种子：0 / 1 / 2
训练预算：30,000 requested steps
最终评估：50 个配对回合/场景/种子
曲线检查点：10k / 20k / 30k
统计：跨种子配对 Student-t 95% CI
```

主比较为：

```text
autoregressive_maskable_ppo - maskable_ppo
```

`Discrete(136)` 方法作为次要动作机制消融基线。

## 4. 三种动作机制结果

下表为三种子均值：

| 场景 | 方法 | 奖励 | 总毁伤 | 高威胁突防率 | 资源成本 | 决策耗时/ms |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| medium | 原始 Maskable | -73.61 | 1.957 | 0.548 | 10.00 | 0.991 |
| medium | `Discrete(136)` | -65.38 | 1.716 | 0.494 | 13.66 | 0.528 |
| medium | 自回归 | -72.39 | 1.961 | 0.528 | 8.73 | 1.187 |
| time_pressure | 原始 Maskable | -92.38 | 2.415 | 0.690 | 9.92 | 0.937 |
| time_pressure | `Discrete(136)` | -80.27 | 2.135 | 0.635 | 13.42 | 0.510 |
| time_pressure | 自回归 | -86.59 | 2.313 | 0.632 | 8.45 | 1.173 |
| heterogeneity_pressure | 原始 Maskable | -76.70 | 2.015 | 0.554 | 10.95 | 0.961 |
| heterogeneity_pressure | `Discrete(136)` | -64.10 | 1.698 | 0.490 | 12.87 | 0.509 |
| heterogeneity_pressure | 自回归 | -74.46 | 1.992 | 0.539 | 9.71 | 1.097 |

自回归方法在所有场景和全部 450 个评估回合中均保持非法动作、分配冲突和过度分配为 0。

## 5. 相对原始 Maskable PPO 的差异

| 场景 | 奖励差 | 毁伤差 | 高威胁突防差 | 资源成本差 |
| --- | ---: | ---: | ---: | ---: |
| medium | +1.213 | +0.0039 | -0.0196 | -1.277 |
| time_pressure | +5.787 | -0.1029 | -0.0579 | -1.470 |
| heterogeneity_pressure | +2.241 | -0.0221 | -0.01483 | -1.239 |

所有主要性能差异的 95% CI 均跨越 0。例如，`time_pressure` 资源成本差为 `-1.47`，95% CI `[-14.23,11.29]`；异质性高威胁突防差为 `-0.01483`，95% CI `[-0.2015,0.1718]`。这些结果是筛选趋势，不能表述为显著优势或统计等价。

自回归方法计算更复杂。`medium` 决策耗时相对原始方法平均增加约 0.196 ms，95% CI `[0.099,0.293]`；相对联合枚举方法在三个场景均增加约 0.59–0.66 ms。

## 6. 冻结门槛判定

| 预设门槛 | 观测结果 | 判定 |
| --- | ---: | --- |
| 非法动作、冲突、过度分配均为 0 | 全部为 0 | 通过 |
| medium 奖励下降不超过 5 | `+1.213` | 通过 |
| medium 毁伤增加不超过 0.10 | `+0.0039` | 通过 |
| time_pressure 奖励下降不超过 5 | `+5.787` | 通过 |
| time_pressure 资源成本增加不超过 0.50 | `-1.470` | 通过 |
| time_pressure 资源成本低于 `Discrete(136)` | `-4.963` | 通过 |
| heterogeneity 高威胁突防平均下降至少 0.02 | `-0.01483` | **未通过** |
| heterogeneity 高威胁突防至少 2/3 种子同向 | 2/3 | 通过 |
| heterogeneity 毁伤增加不超过 0.10 | `-0.0221` | 通过 |

任务九只差高威胁突防平均改善幅度这一项门槛。根据预先冻结的协议，只要一项性能门槛未满足，就不运行条件性的 100k × 5 种子正式实验，也不将阈值从 0.02 回溯调整为 0.014。

## 7. 种子差异与典型失效

`heterogeneity_pressure` 高威胁突防率：

| 种子 | 原始 Maskable | 自回归 | 方向 |
| ---: | ---: | ---: | --- |
| 0 | 0.536 | 0.443 | 改善 |
| 1 | 0.602 | 0.593 | 改善 |
| 2 | 0.524 | 0.581 | 退化 |

`time_pressure` 中，自回归方法的奖励相对原始方法在种子 0 和 1 改善，但种子 2 退化约 30.4；资源成本则在种子 1、2 明显降低，在种子 0 增加。固定顺序方法仍存在明显的训练种子敏感性。

## 8. 机制解释

三类动作机制形成了清晰消融：

- 原始独立动作头资源较节制，但不能保证联合无冲突；
- `Discrete(136)` 联合枚举改善拦截和毁伤趋势，但显著增加资源使用；
- 自回归分解同时实现零冲突和资源节制，但平均拦截表现回落到原始方法附近。

这说明任务八的资源成本问题主要与联合动作参数化有关，自回归分解有效缓解了该问题。剩余的高威胁突防不再能简单归因于动作冲突，更可能与固定单元顺序、单元动作头偏置或异质资源-目标关系表示有关。

## 9. 阶段结论与下一步

任务九的工程目标和 30k 筛选已完成，自回归方法应保留为“零冲突且资源节制”的动作机制基线。由于高威胁突防改善幅度未达到冻结门槛，100k 正式实验暂缓。

下一步先补充单元级动作、`no-op`、资源类型、目标威胁和分配顺序诊断，再开展固定顺序敏感性的小规模消融。只有确认不同顺序仍不能稳定改善异质目标优先级后，才进入 GNN 或资源-目标关系表示研究。
