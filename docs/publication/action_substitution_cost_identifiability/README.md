# 动作替代成本可辨识性稿件：发表工作区

更新时间：2026-07-28

## 1. 工作区用途

本目录用于推进“动作替代成本可辨识性”稿件从现有科学初稿到期刊筛选、投稿、
返修和最终发表的全过程管理。

本目录与项目研究主线隔离：

- 不在此目录启动新算法、训练、rollout 或实验；
- 不修改 BPCE/MCH-PPO、GNN 或项目主线的预注册门控；
- 不以投稿需要为由改写已经冻结的实验结论；
- 若期刊策略要求新增跨环境、跨算法或跨顺序证据，应先作为“超出本聊天边界”
  的研究需求登记，再由项目主线单独决定是否执行。

科学稿和证据源仍以
[`docs/manuscript/action_substitution_cost_identifiability/`](../../manuscript/action_substitution_cost_identifiability/)
为准。本目录只保存发表阶段的分析、决策、编辑和投稿管理产物，不复制权威数据。

## 4. 后续建议产物

后续工作宜在本目录逐步形成以下文件；未完成前不预建空文件：

1. `publication_strategy_decision.md`：独立短文或大论文模块的正式路线裁决；
2. `journal_longlist.md`：候选期刊长名单与官网证据；
3. `journal_shortlist_and_decision.md`：期刊评分、风险与最终选择；
4. `reference_completion_log.md`：E01-E24 元数据核验和引用替换记录；
5. `submission_requirements.md`：目标期刊当期官方要求；
6. `submission_package_checklist.md`：正文、补充材料、声明和投稿元数据；
7. `submission_log.md`：投稿、编辑决定、审稿与返修时间线；
8. `reviewer_response/`：返修信和逐点回复。
