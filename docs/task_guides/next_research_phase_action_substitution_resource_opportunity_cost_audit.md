## 1. 决策摘要

BPCE 短视窗安全—资源双分量标签审计已经触发预注册停止条件。下一项工作不应继续增加视窗、重复数、标签规则或 PPO 剂量，而应另立：

> **动作替代与弹药机会成本可辨识性审计：检验当前射击的资源代价能否由“失去的未来合法动作及其安全价值”稳定识别，而不是由整段轨迹的累计射击成本差识别。**

本阶段首先回答机制问题，不生成在线辅助标签：

```text
time/resource 中的成本差为何接近0或为负？
        ↓
是否因为当前强制射击替代了冻结策略原本会在未来执行的射击？
        ↓
若固定当前射击结果并恢复被消耗的一枚弹药，
恢复的未来行动选择权是否具有跨场景、跨种子的可靠安全价值？
```

只有该机会价值在两个核心场景中均可辨识，才允许另立“机会成本 oracle”任务。即使本阶段通过，也不得直接恢复 BPCE、MCH-PPO 或任何在线辅助训练。

## 2. 证据基线

### 2.1 BPCE-A2 的直接证据

阶段 A2 的正式结果为：

| 指标 | 结果 |
| --- | ---: |
| 短视窗 ENGAGE / STOP / AMBIGUOUS | 15 / 16 / 41 |
| 短视窗可操作标签 | 31/72 |
| 完整回合可操作标签 | 27/72 |
| time-pressure ENGAGE / STOP | 5 / 2 |
| heterogeneity ENGAGE / STOP | 10 / 14 |
| 满足双向覆盖的场景×种子块 | 0/6 |

短视窗只增加4个可操作标签，没有解决跨场景、跨种子可辨识性。

关键槽位差异为：

| 场景/槽位 | 平均短窗成本差 | 成本95%下界大于0 |
| --- | ---: | ---: |
| time/safety | +0.286 | 14/18 |
| time/resource | -0.034 | 0/18 |
| heterogeneity/safety | +0.369 | 12/18 |
| heterogeneity/resource | +1.036 | 12/18 |

`time/resource` 的18个上下文全部为 AMBIGUOUS。正式报告判断，当前强制交战通常替代随机延续中的未来射击，因此未形成确定的累计额外成本。该结果不是扩大样本量可以修复的置信区间问题。

### 2.2 与既有双价值研究的交叉证据

状态条件资源预算与显式双价值实验中：

- safety-value 相关系数约为 `0.49–0.53`；
- cost-value 相关系数仅为 `-0.04–0.13`；
- 三个模型种子的逐场景完整门控为 `0/3`。

这两条实验路线共同指向同一个测量问题：

> `resource_cost_engage - resource_cost_noop` 同时包含当前资源消耗和未来动作替代，不能稳定代表当前动作失去的未来资源选择权。

因此，下一步优先级应从“学习更好的 cost-value”前移到“定义并验证可辨识的资源机会成本估计量”。

## 3. 研究边界

本任务审计的是：

> **冻结策略条件下，一枚当前消耗弹药所对应的未来行动选择权及其安全价值。**

它不是：

- 最优策略下的全局资源影子价格；
- 环境奖励中新的成本项；
- BPCE engagement 标签的又一次改写；
- 状态条件资源预算网络的继续调参；
- 对完整长期资源规划问题的最终解决方案。

若本阶段通过，得到的结论也只能写成“在冻结策略和当前 AirDefense v1 场景下可辨识”，不能直接外推到最优控制或其他任务。

## 4. Problem–Method–Insight

| 层次 | 本阶段表述 |
| --- | --- |
| Problem | 累计资源成本差把当前射击成本与未来射击替代混在一起；当 no-op 只把射击推迟到后续时，当前 engage 不一定增加回合累计成本，从而遮蔽资源机会成本。 |
| Method | 在保持当前射击、命中结果、即时成本和冷却完全相同的条件下，增加“射击后恢复一枚弹药”的嵌套反事实分支，以隔离冻结策略条件下未来弹药选择权的边际安全价值。 |
| Insight | 当前动作的资源机会成本不一定表现为更高的回合累计支出；更直接的可检验对象是该动作导致的未来可行动作集合收缩及其安全后果。 |

该 Insight 目前是待验证命题，不得提前写成论文结论。

## 5. 核心可证伪命题

| 命题 | 支持证据 | 否决证据 | 必需测试 |
| --- | --- | --- | --- |
| P-R1：time/resource 的非正累计成本差主要来自未来射击替代 | 多数 time/resource 上下文中，no-op 分支的后续射击数可靠高于 engage 分支，且该差异解释累计成本差 | 后续射击数没有稳定差异，或累计成本差与替代量方向不一致 | N/E 分支后续射击数、单位成本和时刻分解 |
| P-R2：恢复当前消耗的弹药能够揭示可靠的未来行动选择价值 | E-R 分支更频繁保留或使用未来合法动作，并在两个场景中形成可靠正安全价值 | 恢复弹药很少被使用，或只在单一场景/种子产生安全收益 | E/E-R 嵌套反事实与合法动作集合轨迹 |
| P-R3：机会价值比累计成本差更适合表示资源临界性 | 资源槽的可靠机会价值覆盖高于安全槽，并跨种子出现 | 机会价值与槽位无关、仍高度单向或只反映随机噪声 | 槽位分块、种子分块与单位 transition 功效 |

如果 P-R1 通过而 P-R2/P-R3 失败，允许保留“动作替代解释”，但必须否决“当前环境中存在可训练的通用弹药机会价值”。

## 7. 三分支反事实定义

对同一上下文 `i`、被测单元 `u`、合法目标 `j` 和重复随机带 `r`，构造三个分支。

### 7.1 N：当前 no-op

```text
N(i,u,r):
  被测单元当前强制 no-op
  其他动作保持现有联合动作构造语义
  后续采用冻结策略 stochastic continuation
```

### 7.2 E：当前正常 engage

```text
E(i,u,j,r):
  被测单元当前强制 engage target j
  正常扣除一枚弹药
  正常记录即时射击成本
  正常设置 cooldown
  正常执行命中与目标推进
  后续采用冻结策略 stochastic continuation
```

### 7.3 E-R：当前 engage 后恢复一枚弹药

```text
E-R(i,u,j,r):
  当前步与 E 完全相同
  在当前 env.step 完成后、下一次策略观测生成前：
      仅把被测单元的 ammo 恢复1枚
      上限为当前动作执行前的 ammo
  不退还即时成本
  不修改 cooldown
  不撤销命中、拦截或目标推进
  不恢复其他单元资源
  重新生成 observation 与 action mask
  后续采用冻结策略 stochastic continuation
```

E 与 E-R 必须共享：

- 当前联合动作；
- 当前目标；
- 当前命中随机数；
- 当前奖励分量；
- 当前目标状态变化；
- 后续环境随机带；
- 后续策略 uniform tape。

E-R 的唯一受控状态差异应为：

```text
ammo_E-R[u] = ammo_E[u] + 1
```

若当前步已经终止回合，则记录 `opportunity_not_observable=true`，不得把零差值解释为弹药机会价值为零。

## 8. 目标边缘化

E 和 E-R 对每个合法目标分别执行，再按阶段 A 冻结的条件概率边缘化：

```text
p(j | engage, context)
```

N 分支对同一上下文和重复只运行一次。

不得退回 masked-argmax target。阶段 A 已经表明 target argmax 不是当前主要方向错误，但精确边缘化仍是保留语义完整性的冻结设计。

## 9. 主要估计量

所有“future”指标均从当前动作执行完成后开始累计，排除当前步的直接射击。

### 9.1 未来射击替代

```text
Sub_shot
= future_total_shots(N)
 - future_total_shots(E)
```

```text
Sub_cost
= future_resource_cost(N)
 - future_resource_cost(E)
```

解释：

- `Sub_shot > 0`：当前 engage 替代了后续射击；
- `Sub_cost > 0`：no-op 分支在未来产生了更多资源成本；
- 二者可用于解释为什么完整分支的 `cost(E)-cost(N)` 接近0或为负。

同时记录：

- 被测单元的未来射击数；
- 其他单元的未来射击数；
- 第一次替代射击发生时刻；
- 射击使用的单位类型和单位成本。

### 9.2 恢复弹药的实际复用

```text
Reuse_probe
= future_shots_of_probed_unit(E-R)
 - future_shots_of_probed_unit(E)
```

```text
Reuse_total
= future_total_shots(E-R)
 - future_total_shots(E)
```

若恢复弹药从未形成额外合法动作或未来射击，则不能声称该弹药具有已观测的策略条件机会价值。

### 9.3 合法动作机会集合

逐步记录：

```text
legal_edges(t)
= 合法的“单元—目标”动作边数量
```

```text
high_threat_coverable(t)
= 至少存在一个合法防御单元的高威胁目标数量
```

主要结构差值：

```text
OptionEdge
= sum_t legal_edges_E-R(t)
 - sum_t legal_edges_E(t)
```

```text
OptionThreat
= sum_t high_threat_coverable_E-R(t)
 - sum_t high_threat_coverable_E(t)
```

结构指标只解释恢复弹药是否扩大未来行动集合，不替代最终安全结果。

### 9.4 弹药机会安全价值

分别保留两个安全分量：

```text
AmmoGain_D
= zone_damage(E)
 - zone_damage(E-R)
```

```text
AmmoGain_L
= high_threat_leaks(E)
 - high_threat_leaks(E-R)
```

正值表示恢复一枚弹药改善未来安全结果。

沿用已冻结最小有意义效应：

```text
epsilon_D = 0.05
epsilon_L = 0.10
```

一个上下文被标记为“可靠正机会价值”需满足：

```text
(
  lower95(AmmoGain_D) > epsilon_D
  and lower95(AmmoGain_L) >= -epsilon_L
)
or
(
  lower95(AmmoGain_L) > epsilon_L
  and lower95(AmmoGain_D) >= -epsilon_D
)
```

同时要求：

```text
mean(Reuse_probe) > 0
or mean(OptionEdge) > 0
```

否则安全差异不能归因于恢复弹药形成的未来行动机会。

本阶段不把 `AmmoGain_D`、`AmmoGain_L` 和直接成本加权成单一训练分数。

- 至少12/18个上下文的 `mean(Sub_shot) > 0`；
- 至少6/18个上下文的 `lower95(Sub_shot) > 0`；
- 在累计 `cost(E)-cost(N) <= 0` 的上下文中，至少80%可以由正的 `Sub_cost` 或未来单位成本构成解释；
- 分解重构误差不超过 `1e-6`：

```text
total_cost(E) - total_cost(N)
= immediate_cost(E)
 - immediate_cost(N)
 - Sub_cost
```

若该门控失败，则正式报告中“当前射击替代未来射击”的解释需要撤回或收窄，下一步应检查成本日志与分支语义，而不是设计机会成本模型。

### 11.3 P-R2：机会价值门控

同时满足：

- 每个场景至少6个资源槽上下文具有可靠正机会价值；
- 每个“场景×种子”资源块至少2个可靠正机会价值上下文；
- 每个场景至少80%的可靠正机会价值上下文同时满足 `Reuse_probe > 0` 或 `OptionEdge > 0`；
- 不得依靠单一优势种子满足场景总门槛；
- 可靠正机会价值上下文的安全改善不得主要来自另一安全分量超过容差的恶化。

### 11.4 P-R3：资源临界性门控

作为跨槽位机制门控：

- 两个场景中，资源槽的可靠正机会价值率均高于安全槽；
- 资源槽单位额外 transition 的可靠机会价值数不低于安全槽；
- 最差“场景×种子”资源块不得为0；
- 机会价值不能只由最高成本单元构成，必须报告不同单元类型的覆盖。

阶段总门控只有在 P-R1、P-R2、P-R3 以及完整性门控全部通过时才通过。

## 12. 决策规则

### 12.1 全部门控通过

允许冻结：

> “冻结策略条件下的弹药机会价值”可以由资源恢复嵌套反事实进行估计。

下一项工作只能是独立的**机会成本 oracle 可预测性审计**：

- 使用新状态和独立测试；
- 输入只能读取当前状态、前缀和动作掩码；
- 预测 `AmmoGain_D / AmmoGain_L / OptionEdge`，不预测本轮事后标签；
- 先离线验证跨场景泛化；
- 通过前不得接入 BPCE 或 PPO。

### 12.2 P-R1通过，但P-R2或P-R3失败

保留受控结论：

> 累计成本差失效可以由动作替代解释，但当前环境和冻结策略下，失去一枚弹药的未来安全价值仍不可稳定辨识。

此时停止资源机会成本在线辅助路线，不训练机会成本网络。论文主线转为：

- 累计成本差的结构性混叠；
- 局部反事实资源标签的场景依赖；
- 动作替代条件下的可辨识性边界。

### 12.3 仅异质场景通过

不得报告跨场景通用机制。允许表述：

> 弹药机会价值只在资源异质性形成真实替代稀缺时可辨识。

`time_pressure` 与 `heterogeneity_pressure` 必须分别报告，不能通过合并数据掩盖失败场景。

### 12.4 P-R1失败

撤回“未来射击替代是 time/resource 成本不可辨识主因”的强解释。

下一步只允许：

- 核对即时成本与未来成本分解；
- 检查 N/E 动作构造；
- 检查 stochastic continuation 随机带；
- 检查单位成本异质性是否使射击数和成本方向不一致。

不得继续设计 E-R 标签或机会成本模型。

### 12.5 干预完整性失败

结果作废。优先修复状态恢复与 observation/action mask 重建，不解释任何机制差异。

## 16. 预期论文贡献边界

在实验完成前，只能将本任务描述为一个待验证的机制审计。

若全部门控通过，可形成以下候选贡献：

1. 识别结构化序列分配中累计资源成本差受未来动作替代混叠的问题；

3. 通过场景、种子和资源槽门控验证该机会价值的适用范围。

若只有 P-R1 通过，则贡献必须收窄为：

1. 给出累计成本差失真的受控证据；
2. 证明动作替代解释成立；
3. 报告资源机会价值仍不可辨识的边界。

若 P-R1 也失败，则不能保留“动作替代”作为已证实机制，只能报告原假设被否决。
