# 下一研究阶段：单元顺序偏置与异质目标优先级诊断

更新时间：2026-07-17  
适用环境：`AirDefenseResourceAssignmentEnv v1.0`  
阶段编号：任务十  
阶段状态：已完成（未触发条件性 100k 确认实验）  
阶段主题：逐决策行为诊断、固定顺序消融与关系表示进入条件

## 1. 阶段背景

任务九已经完成固定顺序 `[0,1,2]` 的自回归无冲突策略，并得到以下筛选证据：

- 非法动作率、联合分配冲突率和过度分配率严格为 0；
- `time_pressure` 资源成本相对原始 Maskable PPO 下降 1.47；
- `time_pressure` 资源成本相对 `Discrete(136)` 方法下降 4.96；
- `medium` 奖励和毁伤满足非劣效筛选门槛；
- `heterogeneity_pressure` 高威胁突防率平均下降 0.01483；
- 高威胁突防在种子 0、1 中改善，在种子 2 中退化；
- 平均改善未达到预设 0.02 门槛，因此未运行 100k × 5 种子正式实验。

这说明自回归动作分解已经解决“零冲突与资源节制不能兼得”的问题，但尚未稳定解决异质资源与高威胁目标的匹配。当前存在两个竞争解释：

```text
顺序偏置假设：先决策单元占用关键目标，后续单元只能从剩余目标中选择
表示能力假设：共享 MLP 无法稳定表达资源能力、目标威胁和匹配收益关系
```

任务十先用行为诊断和顺序消融区分这两个解释。

## 2. 核心研究问题

本阶段回答：

> 自回归策略的高威胁突防和种子敏感性，主要来自固定单元顺序造成的条件决策偏置，还是来自 MLP 对异质资源-目标关系的表示不足？

需要进一步回答：

1. 哪个顺序位置获得了更多高威胁目标和优质匹配机会？
2. 强资源、弱资源和低成本资源分别倾向于选择什么目标？
3. 策略在存在合法目标时是否仍过度选择 `no-op`？
4. 高威胁目标突防是因为未被分配、被错误资源分配，还是拦截失败？
5. 改变固定顺序能否在保持零冲突和资源效率的同时稳定降低高威胁突防？

## 3. 研究假设

### H1：顺序位置偏置

固定顺序中的第一决策位置拥有完整目标集合，因此比后续位置获得更高的目标威胁、预期毁伤削减和匹配质量。

### H2：资源角色错配

若高威胁突防由顺序偏置主导，把不同资源轮换到第一位置将显著改变高威胁分配率和突防率。

### H3：顺序稳健性

若三个循环顺序结果接近且高威胁突防仍不稳定，则剩余瓶颈更可能来自资源-目标关系表示，而不是动作冲突或固定顺序。

### H4：性能守恒

任何顺序改进都必须保持零冲突、资源效率、奖励和毁伤，不能通过更积极开火换取高威胁突防下降。

## 4. 阶段边界

- 共享 MLP、Critic 和动作头宽度；

- 动态基础掩码和已分配目标掩码；

### 4.3 暂缓内容

- GNN、图注意力和 Transformer；

- 同时改变动作顺序和状态编码器。

本阶段不能根据结果事后重新定义“高威胁目标”阈值，也不能只报告表现最好的顺序而隐去其余顺序。

## 5. 逐决策诊断设计

### 5.1 新增决策级数据

统一实验新增 `decisions.csv`。每一行对应一个环境决策步中的一个防御单元动作，至少记录：

```text
method, train_scenario, eval_scenario,
run_index, train_seed, episode_index, episode_seed, step_index,
unit_index, resource_type, unit_order_position,
selected_action, selected_target, selected_noop,
base_action_legal, conditional_action_legal,
ammo_before, cooldown_before, energy_before,
num_base_legal_targets, num_conditional_legal_targets,
target_alive, target_threat, target_payload,
target_time_to_impact, target_distance,
hit_probability, damage_potential,
expected_damage_reduction,
target_already_selected_by_prefix,
shot_fired, hit, target_intercepted
```

对于 `no-op`，目标相关字段使用空值，不能用 0 混同真实低威胁目标。

### 5.2 核心诊断指标

按方法、场景、种子、资源和顺序位置聚合：

| 指标 | 定义 |
| --- | --- |
| `assignment_rate` | 非 `no-op` 分配次数 / 决策机会数 |
| `avoidable_noop_rate` | 存在条件合法目标时选择 `no-op` 的比例 |
| `high_threat_assignment_rate` | 分配到高威胁目标次数 / 高威胁目标合法机会数 |
| `mean_assigned_threat` | 所选目标平均威胁 |
| `mean_expected_damage_reduction` | 所选匹配的平均预期毁伤削减 |
| `matching_efficiency` | 实际所选预期削减 / 当时最大可选预期削减 |
| `prefix_denial_rate` | 目标因前序单元占用而不可选的比例 |
| `high_threat_unassigned_rate` | 高威胁目标在仍可拦截时未获任何资源分配的比例 |
| `high_threat_mismatch_rate` | 高威胁目标获分配但不是当时最高预期收益资源的比例 |
| `position_advantage` | 第一位置与后续位置在匹配质量上的差异 |

机会型比例必须使用可解释的分母，并在原始数据中保留分子与分母，不能直接平均回合百分比。

### 5.3 高威胁突防归因

每个高威胁突防目标归入以下互斥类别：

```text
never_legal：整个回合没有任何资源具备合法拦截机会
unassigned：存在合法机会但从未被分配
prefix_denied：关键机会被前序分配占用后丢失
mismatched_resource：被分配给明显较低预期收益资源
attempted_miss：获得合理拦截尝试但随机未命中
resource_exhausted：关键机会出现时资源已耗尽或冷却
```

分类优先级和互斥规则必须在代码与文档中固定，并由合成案例测试。

## 6. 顺序消融设计

默认环境包含两个导弹单元和一个激光单元。第一轮只比较三个循环顺序，使每个单元恰好占据一次第一、第二和第三位置：

```text
order_012 = [0, 1, 2]  # 任务九基线
order_120 = [1, 2, 0]
order_201 = [2, 0, 1]
```

三个逆循环排列 `[0,2,1]`、`[2,1,0]`、`[1,0,2]` 暂不进入首轮训练。只有首轮发现明显位置效应但无法定位相对次序时，再补充完整六排列消融。

方法名建议：

```text
autoregressive_ppo_order_012
autoregressive_ppo_order_120
autoregressive_ppo_order_201
```

模型签名必须包含 `unit_order`，不同顺序模型不能互相误加载。

## 8. 30k 筛选门槛

候选顺序相对任务九 `order_012` 基线必须满足：

| 指标 | 门槛 |
| --- | --- |
| 非法动作、冲突、过度分配 | 全部严格为 0 |
| `medium` 平均奖励 | 下降不超过 5 |
| `medium` 平均毁伤 | 增加不超过 0.10 |
| `time_pressure` 资源成本 | 增加不超过 0.50 |
| `heterogeneity_pressure` 高威胁突防率 | 平均下降至少 0.02，且至少 2/3 种子同向 |
| `heterogeneity_pressure` 平均毁伤 | 增加不超过 0.10 |
| 决策耗时 | 平均增加不超过 25% |

此外，候选顺序相对原始 Maskable PPO 仍需满足任务九的资源成本和性能非劣效门槛。若多个顺序通过，按预先固定的优先级选择：

```text
高威胁突防率 -> 总毁伤 -> 资源成本 -> 奖励 -> 决策耗时
```

筛选门槛用于决定是否进入独立确认实验，不等同于显著性结论。

## 9. 决策规则

```text
决策轨迹是否完整可信？
├─ 否：返回数据记录与聚合修复
└─ 是
   ├─ 某一顺序稳定降低高威胁突防且守住性能门槛
   │  └─ 使用独立种子运行 100k 确认实验
   ├─ 顺序显著改变行为，但没有顺序同时守住全部门槛
   │  └─ 研究顺序不变性或轻量角色条件动作头，仍暂缓 GNN
   ├─ 三个顺序行为和性能接近，高威胁突防仍不稳定
   │  └─ 动作顺序瓶颈基本排除，进入资源-目标关系表示/GNN 设计
   └─ 主要问题来自随机未命中或 never_legal
      └─ 当前场景或随机机制限制可学习上限，先校准环境可辨识性
```

进入 GNN 的必要证据不是“当前 PPO 表现不好”，而是：动作合法性、动作参数化、资源效率和固定顺序均已被单独控制后，异质资源-目标匹配问题仍然存在。
