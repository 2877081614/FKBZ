# W1-10：审稿压力测试与投稿准备

更新时间：2026-07-24  
任务状态：NOT_STARTED  
前置任务：W1-09 通过 T09  
后续任务：M1/M2/M3/M4 阶段出口  
允许并行：可分审稿维度评阅，最终必须统一裁决  
任务性质：对抗性审稿、主张审计、期刊适配和投稿材料准备

## 1. 目标

以怀疑性审稿人视角检查贡献、证据、复现性、边界和写作是否足以支撑既定稿件
定位，并完成目标期刊适配。

本任务可以要求收窄主张或重写章节，但不能自动授权新增实验。

## 2. 输入

- W1-09 中英文完整稿；
- 图表与补充材料；
- 文献定位决策；
- 术语账本；
- Claim–Evidence 与稿件追溯矩阵；
- 未解决占位清单。

## 3. 审稿维度

### 3.1 贡献

- 新知识是否是测量洞见，而不只是恒等式；
- 三项贡献是否分别有证据；
- 与最接近工作是否有 Problem/Method/Insight 层差异；
- 稿件形态是否符合 L1/L2/L3；
- 是否依赖“首次”才能成立。

### 3.2 技术正确性

- N/E 方向；
- 三类替代成本；
- `Sub_shot` 与 `Sub_cost_total`；
- R1 发现和 R2 确认；
- P-C3 失败；
- 首轮账本修正。

### 3.3 实验完整性

- 9/9 来源模型是否无条件保留；
- 108 个上下文是否零重叠；
- 7,776 条账本与统计单位是否一致；
- 图表是否隐藏负结果；
- 资源类型和场景边界是否可见；
- 是否存在结果选择或事后阈值变化。

### 3.4 写作清晰度

- 每段单一功能；
- Introduction 问题与 Results 回答对齐；
- Methods 可复现；
- Results/Discussion 语气分离；
- Title/Abstract/Conclusion 范围一致；
- 中英文术语统一。

### 3.5 实际意义与局限

- 为什么没有在线算法提升仍值得发表；
- 当前发现如何约束后续信用设计；
- 单环境、冻结策略、成本定义和资源类型边界是否充分；
- 是否把未来工作写成未验证承诺。

## 4. 核心攻击点

| 攻击 | 必须回答 |
| --- | --- |
| “只是记账” | 替代导致信用读出符号失真的实证与独立边界 |
| “失败算法包装” | 创新演化透明，最终主张由 R1/R2 独立支持 |
| “事后改公式” | 287/7776、2.0、8.88e-16、未变样本门槛、唯一重跑 |
| “单环境过拟合” | 明确 AirDefense v1 内部结论，不冒充跨环境泛化 |
| “跨资源外推” | 两类均有替代，但 missile 未过符号掩盖门槛 |
| “种子不独立” | 历史用途、未参与标签设计、9/9 无条件保留 |
| “CRN 不现实” | 方差控制角色和分支边缘过程 |
| “没有算法增益” | 测量有效性/诊断协议定位及文献差异 |

## 5. 问题分级

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| R0 | 拼写、格式、局部表达 | 直接修订 |
| R1 | 段落结构或追溯缺失 | 重写或补链接 |
| R2 | 主张超过已有证据 | 收窄、删除或降级动词 |
| R3 | 现有数据存在未完成的只读核查 | 回到冻结数据审计 |
| R4 | 需要新环境、新算法或新实验 | 记录为独立研究问题，不在 W1 执行 |
| RX | 致命完整性冲突 | 暂停投稿，进入 M4 |

不能把 R4 自动转化为“补实验任务”。

## 6. 目标期刊适配

确定目标期刊后核查：

- 文章类型；
- 摘要结构和字数；
- 主文总字数；
- 图表数量；
- Related Work 是否独立；
- Methods 位置；
- 参考文献格式；
- 数据和代码可用性声明；
- 补充材料要求；
- highlights、graphical abstract、author summary 等额外材料。

期刊要求只改变形式，不扩大科学主张。

## 7. 最终主张扫描

全文搜索并逐项裁决：

```text
first
novel
universal
general
robust
state-of-the-art
solve
prove
always
never
```

每个保留词必须有范围和证据。中文稿同步检查：

```text
首次 / 创新 / 通用 / 普适 / 稳健 / 解决 / 证明 / 始终 / 完全
```

## 9. 验收门控 T10

- 每项主要贡献都有正文、图表和数据来源；
- 所有 R2/R3/RX 问题关闭或明确阻断；
- 账本修正透明；
- P-C3 和负结果未隐藏；
- 强动词逐项有证据；
- 目标期刊格式已适配，或明确采用学位论文章节出口；
- 中英文终稿一致；
- 数据/代码可用性不含虚假承诺；
- 未把 R4 问题偷偷扩展进 W1。

新的任务报告中重新定义和预注册。
