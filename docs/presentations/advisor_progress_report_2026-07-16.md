### 第 2 页：研究背景与核心问题

页面要点：

- 多架无人机持续来袭；
- 防御资源数量、弹药和作用范围有限；
- 防御单元类型异构，命中具有随机性；
- 目标威胁、载荷、到达时间和攻击区域不同；
- 当前决策会消耗资源并影响后续防御能力。

核心问题：

> 在有限资源和随机拦截条件下，如何动态分配异构防御资源，以最小化重要区域损伤？

为什么考虑强化学习：

- 决策具有明显的时序依赖；
- 联合分配动作随资源和目标数量快速增长；
- 需要权衡当前拦截收益与后续资源保留；
- 简单优先级规则难以同时处理威胁、损伤、资源成本和分配冲突。

这一页不要展开讲算法公式，重点让导师先认可问题本身。

### 第 3 页：问题建模与研究边界

当前采用集中式 MDP 建模：

| 概念 | 当前定义 |
| --- | --- |
| Agent | 防空编组集中式指挥决策器 |
| Environment | 目标运动、拦截概率、资源消耗、冷却和区域损伤 |
| State | 保护区域、目标威胁与到达时间、防御单元资源状态 |
| Action | 为每个防御单元联合选择目标或不行动 |
| Reward | 拦截收益、区域损伤、资源消耗、冲突、过度分配和非法动作 |
| Objective | 在有限资源条件下最小化重要区域损伤 |

需要主动说明研究边界：

> 当前环境是决策级简化仿真，重点研究动态资源分配，不是高保真雷达、电磁或弹道仿真。

当前暂未加入：

- 真实雷达方程和复杂探测链路；
- 通信延迟与局部观测；
- 干扰与软杀伤资源；
- 高保真三维弹道；
- 攻防双方同时学习。

### 第 4 页：AirDefenseResourceAssignmentEnv v1.0

环境包含：

- 2 个保护区域；
- 3 个异构防御单元；
- 每回合 5 个随机来袭目标；
- 目标属性：威胁、载荷、攻击区域、到达时间和规避能力；
- 防御单元属性：类型、位置、弹药、射程、命中概率、成本和冷却；
- 联合动作空间 `MultiDiscrete`；
- 每个防御单元独立的动作掩码；
- 区域损伤、冲突和过度分配奖励项。

建议展示以下材料：

- [v1.0 环境架构图](../environments/air_defense/air_defense_v1_architecture_diagram.md)
- [v1.0 场景图说明](../environments/air_defense/air_defense_v1_scenario_diagram.md)
- [默认场景图](../environments/air_defense/air_defense_v1_scenario_seed0.png)

建议讲法：

> v1.0 中的 agent 代表集中式指挥决策器。每个时间步需要同时为多个防御单元选择目标，因此动作不是单个“资源—目标对”，而是一个联合分配向量。动作掩码负责排除没有弹药、处于冷却、超出射程或目标已经失效等物理上不可能的动作。

### 第 6 页：正式实验设计

对比方法：

```text
规则方法：
random_joint
nearest_joint
highest_threat
time_to_impact
greedy_damage

学习方法：
PPO
Maskable PPO
```

实验协议：

| 项目 | 设置 |
| --- | --- |
| 训练种子 | `0, 1, 2, 3, 4` |
| 请求训练步数 | `100,000` 步/模型 |
| 实际训练步数 | `100,096` 步/模型 |
| 最终评估 | `100` 回合/场景块，共 `500` 回合/方法 |
| 曲线评估频率 | 每 `5,000` 步 |
| 曲线评估回合 | 每个检查点 `20` 回合 |
| 统计方式 | 5 个实验运行上的 Student-t 95% 置信区间 |
| 公平性控制 | 所有方法使用相同的配对评估场景块 |

需要强调：

> 这不是一次随机训练结果，而是 5 个训练种子和固定评估协议下的正式对比。

### 第 7 页：核心实验结果

建议主页面只展示三种关键方法：

| 方法 | 平均奖励 | 成功率 | 拦截率 | 突防率 | 平均损伤 | 非法动作 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Maskable PPO | -35.93 | 0.082 | 0.561 | 0.296 | 1.052 | 0.00 |
| greedy_damage | -38.75 | 0.074 | 0.517 | 0.304 | 1.052 | 0.00 |
| PPO | -86.52 | 0.000 | 0.398 | 0.438 | 1.534 | 6.84 |

完整结果见：

- [正式实验报告](../experiments/air_defense_v1_formal_benchmark_100k.md)
- [跨种子汇总数据](../../results/air_defense_v1/formal_benchmark_100k_5seeds_20260714/summary.csv)

建议先讲第一个结论：Maskable PPO 明显优于普通 PPO。

配对差异：

- 平均奖励提高 `50.60`，95% CI `[8.24, 92.95]`；
- 拦截率提高 `0.163`；
- 突防率降低 `0.142`；
- 平均损伤降低 `0.482`；
- 非法动作从平均 `6.84` 降为 `0`。

### 第 8 页：结果解释与学习曲线

建议展示：

![5k 步后的学习曲线](../../results/air_defense_v1/formal_benchmark_100k_5seeds_20260714/learning_curves_post_warmup.png)

关键观察：

1. Maskable PPO 的主要改善发生在约 40k～80k 步；
2. 80k 后奖励和损伤基本进入平台；
3. 普通 PPO 早期先学习成近似“不行动”策略；
4. 普通 PPO 后期恢复部分拦截能力，但成功率始终为 0；
5. 普通 PPO 的非法动作在训练后期重新增加；
6. Maskable PPO 全程保持非法动作数为 0。

需要谨慎解释 Maskable PPO 与 `greedy_damage` 的关系：

- 奖励均值提高 `2.83`；
- 拦截率平均提高 `0.044`；
- 平均减少约 `1.70` 发弹药；
- 但这些配对差异的 95% CI 均跨 0。

正确表述：

> Maskable PPO 已经达到强规则基线水平，并表现出更好的资源使用趋势，但当前 5 个种子的证据还不能证明它稳定超过 greedy_damage。

不要表述为：

> Maskable PPO 已经显著超过所有规则算法。

建议主动说明：

> 动作掩码已经被证明是必要约束机制，但它本身更接近可靠 baseline，而不是最终学术创新。当前项目刚刚从工程平台搭建进入核心研究问题探索阶段。

> 面向异构防空资源—目标动态分配的约束感知图强化学习方法。

- 不同目标数量下的策略泛化。

## 5. 导师可能提问及建议回答

### 问题 1：为什么一定要使用强化学习？

建议回答：

> 不是假设强化学习一定优于优化算法，而是因为该问题存在连续来袭、随机命中和资源跨时刻消耗，当前决策会改变后续可行动作集合。强化学习适合学习长期策略，但后续必须加入 Hungarian 或组合优化基线，证明它在动态场景下的价值。

### 问题 2：Maskable PPO 是否已经是创新点？

建议回答：

> 目前不能这样定义。动作掩码证明了约束处理的重要性，但 Maskable PPO 是已有算法。它当前的作用是建立可靠 baseline，并为后续约束感知的图结构策略提供实验依据。

### 问题 3：为什么成功率都这么低？

建议回答：

> 当前成功判据要求所有目标消失且区域损伤为 0，条件比较严格；默认场景同时包含有限弹药、随机命中和 5 个目标，因此属于偏难场景。下一步会建立难度分层，并同时报告损伤、拦截率和资源效费比，避免只依赖成功率。

### 问题 4：Maskable PPO 是否超过 greedy_damage？

建议回答：

> 均值上略高，但配对置信区间跨 0，所以目前只能说达到强规则基线水平，不能宣称稳定超过。这个结果说明还需要更强的状态表示、动作结构或跨场景学习机制。

### 问题 5：v1.0 是不是最终环境？

建议回答：

> 不是。v1.0 是集中式、完全可观测的决策级基准环境，用来确认任务和算法链路。后续会逐步加入难度配置、探测不确定性、干扰资源、局部观测和多智能体接口，但不会一次性加入所有复杂因素。

### 问题 6：为什么现在不直接做多智能体？

建议回答：

> 当前先用集中式环境确认奖励、动作约束和任务难度，避免把环境问题与多智能体非平稳性混在一起。集中式基准稳定后，再扩展 PettingZoo 和 MAPPO，能够更清楚地判断性能变化来自哪里。

### 问题 7：当前环境与实际防空任务有多大距离？

建议回答：

> 当前保留了区域价值、目标威胁、载荷、到达时间、异构资源、射程、弹药、冷却和随机命中等决策关键因素，但没有追求雷达、电磁和弹道高保真。后续需要根据研究目标决定是继续研究决策机制，还是引入真实参数进行校准。

### 问题 8：下一篇论文准备创新什么？

建议回答：

> 目前最有依据的方向是资源—目标图表示和约束联合分配。现有实验说明动作合法性很关键，同时普通 MLP 对异构资源、动态目标数量和关系结构表达有限。下一步会先通过难度和泛化实验确认瓶颈，再决定图注意力、结构化动作或多智能体协同的具体形式。
