# 防空资源智能分配研究创新路线图

更新时间：2026-07-29

当前阶段：N3 FCRC 冻结成对预测验证完成，预测命题否决

路线状态：第一创新的测量模块以 L2/M2 冻结；FCRC 只保留为静态解释组件，
BPCE/MCH-PPO、FCRC在线约束、在线训练与 GNN 均不作为已验证贡献

## 1. 最终研究目标

本项目的最终目标不是“使用 GNN”，而是形成一种面向异质防空资源、动态目标数量和复杂约束的智能资源分配方法，使其同时具备：

- 稳定的交战决策；
- 合理的资源-目标匹配；
- 严格的合法动作与无冲突约束；
- 可控的资源消耗和高威胁突防风险；
- 跨场景、跨编组和跨规模泛化能力；
- 可解释、可复现的训练与失效诊断。

GNN 是后续实现关系建模、批量反事实估值和变规模泛化的候选工具，不是研究终点。

## 2. 当前科学问题

任务十二已经排除或控制了环境接口、非法动作、分配冲突、简单关系 scorer 容量和普通动作因子化等因素。当前主要瓶颈为：

```text
同一 PPO 配置在不同随机种子下产生两极策略
├─ all-noop / 低交战
└─ 高交战 / 高资源成本
```

已有证据表明：

- deterministic argmax 会放大概率碎片化；
- stochastic 与 deterministic 交战率最大差异达到 0.404；
- 10k 诊断中 5 个种子有 3 个进入 all-noop；
- 交战-目标因子化没有消除分叉；
- 实际交战时目标匹配通常不是首要瓶颈。

因此，当前必须研究交战概率校准、联合 advantage 信用混叠和 Critic 估值误差，不能直接把问题归因于图表示能力。

## 3. 两级创新假设

以下内容是待验证的创新假设，不得在论文或汇报中提前表述为已经成立的创新点。

### 3.1 第一创新假设

暂定方向：

> 动态合法动作约束下的掩码感知反事实分层 PPO

候选名称：

```text
Mask-aware Counterfactual Hierarchical PPO, MCH-PPO
```

拟解决的问题：标准联合 advantage 同时更新“是否交战”“攻击哪个目标”和“哪个单元执行”，无法区分各决策成分对最终回报的边际贡献。

成立所需的差异点：

- 集中式策略内部的单元-交战-目标结构化信用分配；
- 反事实计算感知动态动作掩码、前缀占用和目标不可重复约束；
- engagement 与 target 使用独立 advantage、ratio、clip/KL 和诊断；
- 资源成本采用显式约束或可解释的对偶机制；
- 给出无偏性、方差或受限更新性质中的至少一项理论分析。

### 3.2 第二创新假设

暂定方向：

> 面向变规模防空分配的类型化二部图反事实 Critic

该方向不是普通“PPO + GNN”。GNN 必须承担明确算法功能：

- 表示资源、目标和保护区的类型化关系；
- 一次前向传播估计多个合法反事实动作价值；
- 适配动态合法边和前缀目标占用；
- 支持未见资源数、目标数和编组结构的零样本或少样本泛化；
- 降低反事实估值的时间与空间复杂度。

第二创新只有在第一阶段稳定交战决策后才进入实现。否则 GNN 结果仍会被 PPO 信用分配不稳定性混淆。

## 4. 已知相关工作与创新边界

必须重点区分以下已有路线：

| 已有路线 | 与本项目的重叠 | 本项目必须形成的差异 |
| --- | --- | --- |
| COMA | 反事实基线、个体贡献 | 集中式结构化动作、动态掩码、交战-目标双层信用 |
| H-PPO | 分层/参数化动作 PPO | 离散交战-目标关系、反事实 advantage、资源约束 |

| GNN/GAT-WTA | 图关系与规模泛化 | 图反事实 Critic、批量反事实估值与信用分配耦合 |

## 6. 论文产出条件

仅在以下条件同时满足时，才具备较好期刊论文的基本支撑：

- 系统查新证明方法差异不是已有模块的简单拼接；
- 机理实验确认联合 advantage 信用混叠与种子分叉相关；
- 新方法在至少 5 个独立种子中消除塌缩；
- 奖励、毁伤、高威胁泄漏和资源成本同时改善或非劣；
- 与 PPO、Maskable PPO、H-PPO、COMA/HAPPO 类方法进行公平对照；
- 在通用结构化分配任务或第二环境中复现收益；
- 给出消融、复杂度、统计显著性和失败边界；
- 图结构阶段验证训练规模外的资源数和目标数。

当前项目已经形成清晰的问题链和实验基础，但尚未达到可以保证论文录用或宣称创新成立的阶段。

## 7. 当前决策

安全临界采样与类别平衡正式实验已完成144个全新状态、196个 targeted 上下文组和每分支32次共同随机数 rollout。四组旧测试观测重叠均为0。新 test 有74个可靠组，其中28个 engage、46个 no-op；engage 比例从随机采样的 `5.3%` 提高到 `37.8%`，三个场景均达到正类功效。

validation 冻结 `balanced_bce_margin`。正式 test 三种子 balanced accuracy 为 `0.758 / 0.711 / 0.708`，相对风险回归提高 `0.146 / 0.128 / 0.125`；false-noop 降至 `0.071 / 0.143 / 0.214`。这证明安全临界采样与类别平衡符号学习有效恢复了必要交战识别。

完整门控仍未通过。seed20/21 的 wasteful-engage 恶化，且 `time_pressure` no-op recall 仅为 `0.455 / 0.182 / 0.273`。三种子均因逐场景停止边界失败，整体通过数 `0/3`。因此当前问题已从“模型看不见必要交战”收窄为“模型能交战但缺少资源约束下的停止边界”。

下一步只允许离线校准交战决策边界，不直接训练 MCH-PPO：

- 冻结 margin 模型、风险效用、oracle、本轮正式 test 和所有门槛；
- 在新 validation 数据上比较 no-op recall 约束阈值与对偶代价；
- 区分全局阈值和状态依赖资源预算，禁止直接使用 test 调参；
- 保持 false-noop 与 wasteful-engage 双非劣；
- 冻结 conditional-target 层和临界度采样协议。

继续冻结：

- AirDefense v1.0 环境和奖励；
- GNN、GAT 和 Transformer；
- 大规模环境扩展；
- MCH-PPO 的最终结构；
- 100k 正式实验。

只有资源约束校准后的非图 engagement estimator 在新的独立状态上至少2/3训练种子同时通过 false-noop、wasteful-engage、逐场景召回和计算成本门槛，才冻结完整 MCH-PPO。当前数据功效和基本表示能力已经通过，但停止边界尚未通过。该失败仍不能自动触发 GNN；图结构需等待关系匹配、批量估值效率或跨规模泛化成为主要瓶颈。

## 8. 资源约束边界校准后的路线更新

更新时间：2026-07-21。本节覆盖第7节中“下一步只允许离线校准”的待执行状态。

资源约束边界校准已完成。72个全新状态形成84个上下文组和81个可靠 oracle，数据与功效全部通过。全局阈值和成本-弹药资源对偶在 validation 上均为 `0/3` 可行；被选中的资源对偶在独立 test 上 BA 为 `0.593 / 0.612 / 0.605`，no-op recall 为 `0.38 / 0.32 / 0.34`，整体仍为 `0/3`。

该结果否决的是“冻结交战 logit + 固定标量资源压力即可恢复停止边界”，而不是否定资源约束本身。成本和弹药对 no-op 有弱区分方向，但无法独立表达目标紧迫度、未来目标流、剩余总预算和替代资源能力。

当前路线更新为：

```text
标量资源阈值/对偶校准
        已完成；validation 无可行解，独立 test 0/3
                    ↓
状态条件预算与显式约束价值诊断
        独立 calibration / test + 安全-资源 Pareto 门控
                    ↓ 条件通过
最小 MCH-PPO 30k 独立种子筛选
                    ↓
MCH-PPO 100k 正式验证
                    ↓
类型化图反事实 Critic与跨规模泛化
```

下一阶段不得继续扩大 `tau/lambda` 标量网格，也不得直接用 Actor 训练掩盖离线边界失败。应首先定义可解释的 episode/状态资源预算，估计安全价值与资源消耗价值，并使用独立或交叉拟合 calibration 防止重复使用同一 validation。GNN 仍不是当前瓶颈的解法。

## 9. 状态条件预算后的路线更新

更新时间：2026-07-21。本节覆盖第8节中的待执行状态。

状态条件安全/成本双价值正式实验已完成。三折交叉拟合选择 state-budget，并在全新72状态 test 上使三种子总体 BA 达到 `0.834 / 0.776 / 0.768`，no-op recall 达到 `0.702 / 0.719 / 0.737`，wasteful-engage 降至 `0.298 / 0.281 / 0.263`。总体安全和资源停止门槛首次同时通过。

完整门控仍因局部场景召回为 `0/3`。失败已从全局结构性塌缩变为小范围跨场景边界漂移：两个种子在 time-pressure 少量过度交战，一个种子在 medium 偏保守且在 heterogeneity 偏激进。成本价值相关性仍弱，是当前最明确的可修订对象。

当前路线更新为：

```text
状态条件资源预算与显式双价值
        已完成；总体门槛3/3，逐场景完整门槛0/3
                    ↓
跨场景鲁棒预算与可靠成本差监督
        最坏场景选择 + 新独立 test，要求至少2/3完整通过
                    ↓ 条件通过
MCH-PPO 公式、接口与理论假设冻结
                    ↓
30k × 3 seeds 筛选
                    ↓
100k × 5 seeds 正式实验与论文证据闭环
```

因此距离 MCH-PPO 创新实验预计只剩一项前置任务。该任务不得改变环境、oracle、双价值语义或扩大模型容量，只解决跨场景选择和 cost-delta 监督。GNN 继续等待 MCH-PPO 稳定性门槛通过。

## 10. 跨场景鲁棒实验后的路线修正

更新时间：2026-07-21。本节覆盖第9节“只剩一项前置任务”的乐观估计。

场景-类别等权、最差块惩罚和可靠成本差监督未形成跨种子一致收益。OOF 仍选择 standard；在另一批72状态 test 上，seed21/22 的异质场景 engage recall 降至 `0.273 / 0.182`，与上一批全部为1.0的方向相反。当前证据表明失败来源是同一场景内部的临界状态批次漂移，普通随机 state folds 无法模拟这种分布变化。

路线更新为：

```text
场景级鲁棒预算与可靠成本监督
        已完成；鲁棒候选未被选择，新批次0/3完整通过
                    ↓
多批次临界状态语料与 leave-one-batch-out
        验证批次外安全收益符号和预算稳定性
                    ↓ 条件通过
独立最终批次确认
        至少2/3种子完整通过
                    ↓
MCH-PPO 公式、接口与理论假设冻结
```

因此进入 MCH-PPO 前至少还需要“多批次构建/留批次验证”和“最终独立批次确认”两个门控步骤，它们可在同一研究任务中连续执行。该结果仍不能触发 GNN，因为尚未证明关系表示容量是批次漂移的主要原因。

## 11. 多批次留一验证后的路线修正

更新时间：2026-07-21。本节覆盖第10节中“多批次验证后即可独立确认”的预期。

三个独立训练批次共形成144个状态和193个上下文组，可靠 engage/no-op 组分别为68/115，批次间与全部历史测试集均无状态重叠。选中的 reliable-cost 鲁棒目标在 leave-one-batch-out 中仅 `1/3` 种子可行；第四个72状态独立批次中，三种子 engage recall 为 `0.829 / 0.943 / 0.886`，但 no-op recall 仅为 `0.500 / 0.477 / 0.545`，完整通过数为 `0/3`。全部九个种子-场景组合的 no-op recall 均低于0.65。

多批次覆盖修复了上一批异质场景中的漏交战，却将误差方向推向系统性过度交战。由于数据功效、批次独立性和回报重构均已通过，当前不能把失败归因于样本不足，也不能直接用更多随机数据替代机制分析。

路线更新为：

```text
多批次临界状态语料与 leave-one-batch-out
        已完成；留批次1/3可行，最终独立批次0/3完整通过
                    ↓
留一批次安全-停止 Pareto 可行性审计
        复用现有 rollout，搜索跨批次/跨场景共同可行边界
                    ↓ 条件可行
独立批次确认
        至少2/3种子完整通过
                    ↓
MCH-PPO 公式、接口与理论假设冻结
```

若现有模型输出存在跨批次共同可行的 Pareto 边界，则冻结选择规则并只做一次独立确认；若不存在，则必须修改价值语义或显式约束结构，而不是继续调标量阈值。MCH-PPO 和 GNN 均继续冻结，后者仍不是当前安全-停止决策冲突的直接解法。

## 12. OOB Pareto 审计后的路线更新

更新时间：2026-07-22。本节落实第11节的可行性判定。

完整 OOB 阈值扫描使冻结 reliable-cost 目标的可行种子数由零阈值的 `1/3` 提升为 `3/3`。三个种子均能找到同时满足总体、逐批次、逐场景双类召回和安全收益符号约束的阈值。因此当前价值 score 仍具有可用排序信息，失败不应再被描述为价值语义完全不可分。

可行性尚不等于稳定性。seed22 只有两个可行阈值，最小余量为0；种子级选定阈值为 `0.1052 / 0.0288 / 0.3540`，显示原始 score 尺度明显漂移。共享阈值最多通过2/3种子，也不能替代种子级校准。

路线更新为：

```text
OOB 安全-停止 Pareto 可行性审计
        已完成；零阈值1/3，种子级鲁棒阈值3/3
                    ↓
一次全新独立批次确认
        冻结目标、阈值选择协议和门槛，要求至少2/3完整通过
                    ↓ 条件通过
MCH-PPO 公式、接口与理论假设冻结
                    ↓
30k × 3 seeds 最小筛选
                    ↓ 条件通过
100k × 5 seeds 正式实验
```

独立确认前不得用新批次回调阈值，也不得新增目标函数、放宽约束或启动 Actor 训练。GNN 继续等待 MCH-PPO 稳定性和关系建模必要性证据，不作为当前校准问题的直接解法。

## 13. 独立确认后的路线修正

更新时间：2026-07-22。本节执行第12节预注册的唯一独立确认。

新确认批次的数据完整性和功效门控全部通过：72个状态、81个可靠组、三场景双类别完整，与19个历史数据集重叠为0。冻结 OOB 阈值没有形成跨批次泛化，三种子完整通过数为 `0/3`；BA 为 `0.625 / 0.646 / 0.625`，no-op recall 为 `0.478 / 0.435 / 0.565`。seed22 使用较高阈值后仍未满足停止召回，同时异质场景 engage recall 降至 `0.364`。

safety sign accuracy 保持在 `0.740-0.753`，说明模型仍能学习部分安全方向，但 score 的尺度、排序裕量和安全-资源折中没有跨批次稳定。该结果否决的是“种子级固定 OOB 阈值足以恢复离线门控”，不是否定反事实价值学习本身。

路线更新为：

```text
冻结 OOB 校准的唯一独立确认
        已完成；数据合格，固定阈值0/3
                    ↓
跨批次尺度对齐与不确定性/显式约束机制
        禁止回调确认阈值，要求新的可预注册决策语义
                    ↓ 条件通过
新的独立门控
        至少2/3种子完整通过
                    ↓
MCH-PPO 公式与接口冻结，再进入30k × 3 seeds筛选
```

当前不再用更多随机批次或标量阈值搜索替代机制修订。MCH-PPO继续冻结，因为不稳定的离线 Critic 边界会被 Actor 更新放大；GNN也继续冻结，因为本次失败仍未证明关系表示容量是主要原因。

## 14. 统一概率与不确定性校准后的路线修正

更新时间：2026-07-22。本节执行第13节提出的跨批次尺度和不确定性修订。

四个预注册线性概率候选在外层 leave-one-batch-out 中均为 `0/3`。最佳 score Platt 平均 BA 达到0.781，但最差批次和最差场景 no-op recall 全部失败。加入 safety、cost、budget 和场景后，预测标准误明显上升；LCB保守化在部分种子减少过度交战，却使另一个留出批次的 engage recall 降为0。

该结果进一步排除了“只要把 score 变成统一概率并惩罚不确定性即可”的解释。当前真正缺失的是多约束决策语义：模型需要分别表达安全收益的可信下界、资源成本的可信上界、目标紧迫度和停止可行性，而不是先压缩成一个 score 再校准。

路线更新为：

```text
跨批次统一概率与LCB校准
        已完成；四候选均0/3，未生成新rollout
                    ↓
显式安全-资源多约束价值与可行域
        分离下界/上界/停止约束，外层留批次验证
                    ↓ 条件通过
唯一独立门控
        至少2/3种子完整通过
                    ↓
MCH-PPO公式与接口冻结，进入30k × 3 seeds筛选
```

这是当前允许的最后一类非图 Critic 结构修订。若显式多约束表示仍不能在外层批次验证中形成可行域，则应暂停 MCH-PPO 主线并重新审视 oracle/任务可辨识性，而不是继续增加数据或校准器。GNN仍等待关系表示瓶颈证据。

## 15. MCH-PPO v0 与 RG-MCH-PPO 在线验证后的路线修正

更新时间：2026-07-22。

根据停止堆叠外围前置任务的决策，项目直接实现并运行了 MCH-PPO v0。纯反事实 actor advantage 在10k、三种子、两个核心场景中出现3/6个绝对 no-op 塌缩，两个场景的平均高威胁突防和损伤均退化，证明不稳定离线 Critic 信号会被 actor 更新放大。

随后实现 RG-MCH-PPO：保留 on-policy GAE，只加入可靠度加权、幅度受限的反事实残差。该修改在两个场景均优于 MCH v0；异质场景相对 factorized PPO 的奖励提高14.49、损伤下降0.320、高威胁突防下降0.081。由此确认 GAE 锚定和局部反事实修正是有效方向。

总门控仍失败。RG-MCH 有2/6个运行塌缩，异质场景成本比为1.259。engagement 集成一致性可靠度和门控激活率高达0.884/0.888，说明多个 Critic 会在共同分布外状态上一致犯错。下一路线不再回到纯离线阈值校准，也不搜索单一融合系数，而是：

```text
MCH-PPO v0 在线压力实验
        已完成；纯反事实信用失败
                    ↓
RG-MCH-PPO GAE锚定与有界残差
        已完成；两场景优于v0，异质场景出现正收益
                    ↓
支持感知可靠度 + engagement累计漂移约束
        区分“Critic彼此一致”与“状态处于可信支持域”
                    ↓ 条件通过
30k × 5 seeds 消融与正式主实验
                    ↓
GNN关系批量估值与跨规模泛化
```

当前已经进入算法创新核心工作，并获得第一个在线正机制证据；但 RG-MCH 仍是候选原型，不能作为论文最终算法结论。

## 16. SA-RG-MCH 支持感知实验后的路线修正

更新时间：2026-07-23。

SA-RG-MCH 使用原Q-Critic数据集338条train行构建状态-单元-前缀-掩码最近邻支持域，并以支持度乘以ensemble agreement；同时使用初始actor Bernoulli KL=0.10作为累计engagement漂移预算。10k三种子双场景实验有5/6个同场景运行绝对all-noop塌缩，全面劣于RG-MCH。

支持诊断显示engagement/target context support仅0.124/0.022，组合可靠度0.114/0.014，反事实残差被压到0.049/0.008。初始anchor KL仅0.017，预算从未激活。该结果说明现有Critic的在线支持覆盖确实不足，同时平滑KL无法检测deterministic 0.5阈值的小幅跨越。

更重要的是，反事实残差关闭后，现有层级优化器使用joint GAE但分别计算engagement/target ratio与clip，并不等价于已验证的factorized PPO joint ratio与joint clip。SA-RG的5/6塌缩否决了“独立层级clip可以作为安全fallback”的假设。

路线更新为：

```text
SA-RG-MCH支持门控与初始KL锚点
        已完成；5/6塌缩，机制否决
                    ↓
Joint-backbone counterfactual PPO
        标准joint PPO surrogate不可替代
        支持感知反事实信用仅作为辅助损失
        gate=0时数值严格等价factorized PPO
                    ↓
deterministic engagement margin/coverage诊断
        直接监控0.5决策边界，不再用平滑KL代替
                    ↓ 条件通过
30k × 5 seeds消融与论文主实验
                    ↓
GNN关系估值与跨规模泛化
```

下一步仍是核心算法优化器工作，不再扩展离线支持距离、KL预算或随机种子。

## 17. BPCE-PPO v0 核心算法路线冻结

更新时间：2026-07-23。

当前正式候选为 **Boundary-Probed Counterfactual Engagement Auxiliary
PPO（BPCE-PPO）**。创新主张不再是宽泛的“反事实分层 PPO”，而是：

> 在动态掩码自回归资源分配中，以标准 joint PPO 为严格安全主干，只在
> 当前策略 engagement 决策边界上执行成对共同随机数干预，并将可靠的
> engage-noop 回报方向作为局部排序辅助。

路线冻结为：

```text
SA-RG-MCH 独立层级 fallback
        已否决；5/6同场景塌缩
                    ↓
BPCE-PPO v0 软件与反事实语义验收
        环境快照 + 索引随机带 + 严格退化测试
                    ↓
256步 smoke
        只验证可运行性、标签和成本，不选择成功结果
                    ↓
10k × 3 seeds × 2 scenarios 机制证伪
        对照 factorized PPO、等预算随机探测和历史失败候选
                    ↓ 条件通过
30k × 5 seeds 消融
                    ↓ 条件通过
100k × 5 seeds 正式实验与第二任务验证
                    ↓
GNN关系表示与跨规模泛化
```

BPCE-PPO v0 不修改环境奖励、动作掩码、策略表示、value head、目标条件
策略或单元顺序。第一版不引入 target 辅助损失、PCGrad、额外 Critic、
学习式门控或新的安全约束，以便将因果归因限制在“边界探测是否能够稳定
修正 engagement 决策”。

正式10k结果产生前冻结：边界半径、每次探测上下文数、重复数、探测间隔、
方向一致性门槛、最小回报效应和辅助系数。扩大实验只在完整三种子双场景
门控通过后启动，不允许根据单个优势种子改变配置。GNN继续冻结，但仍作为
第一创新稳定后解决关系表示和跨规模泛化的第二创新方向。

### 17.1 v0 执行结果

BPCE-PPO v0 已完成软件实现和10k三种子双场景验证。严格 fallback、
保存加载、共同随机带和统一 benchmark 均通过；正式训练时间比为1.940x。

总门控失败：2/6运行绝对all-noop，time-pressure总体安全退化；
heterogeneity-pressure虽然奖励提高21.686、损伤下降0.509，但资源成本为
baseline的1.928倍。边界探测只在time-pressure优于随机探测，在异质场景
不成立。

路线收窄为：

```text
BPCE-PPO v0
        joint fallback成立；局部反事实有条件收益

                    ↓

        正负证据双向覆盖门控
```

该修订仍属于第一创新的核心机制，不引入GNN。若双向覆盖和剂量控制仍不能
减少种子分叉，则应否决“稀疏边界辅助足以稳定joint PPO”的命题，而不是

### 17.2 标签语义审计结果

72上下文只读审计比较了argmax-det、目标边缘化deterministic和目标边缘化

### 17.3 短视窗双分量审计后的停止决策

## 19. N2 从回报责任转向未来任务可行域

更新时间：2026-07-29。

N2 将主线从“如何分解当前动作的实现回报”转向：

> 当前合法动作是否消耗了其他威胁不可替代的未来覆盖能力？

候选 FCRC 对当前目标作双分支排除，只计算资源占用对其余威胁最大加权
匹配值的损失：

```text
当前合法前缀
        动态mask仅保证此刻合法
                    ↓
排除当前目标，计算其余威胁最大可覆盖值
                    ↓
确定性消耗当前资源，不运行continuation
                    ↓
再次计算其余威胁最大可覆盖值
                    ↓
差值 = 当前动作的未来覆盖责任外部性
```

静态开发门控结果：

- 86/243 合法动作外部性为正；
- 34/108 context 存在同单元目标间差异；
- 与成本和威胁权重均无高度相关；
- 平均计算时间 1.02 ms/context；
- N2-P1 至 P5 达到进入预测性验证的条件。

当前路线不是“FCRC-PPO”，而是：

```text
N2静态非退化
        已通过
                    ↓
冻结paired predictive validation
        N3已执行
                    ↓
无增量预测价值且主方向不显著
        已降为解释组件并停止
                    ↓
约束或shield接口
        未授权
```

该顺序避免再次把可计算标签直接包装成在线算法。N3 已否决 FCRC 的当前
预测性机制，因此不再为它设计 GNN 近似器。未来只有在独立的新关系估值或
跨规模泛化瓶颈成立后，GNN 才能作为新任务重新论证。

## 20. N3 FCRC 预测命题否决

更新时间：2026-07-29。

N3 在九个场景—种子区组的32个全新上下文上执行64次共同随机数重复。
high-low其他威胁截获损害差均值为0.0184，但单侧符号翻转`p=0.3511`；
FCRC候选级Spearman为0.4153，却未使留一区组CV MAE相对0.137041基线
产生任何下降。heterogeneity方向为负，总体泄漏损伤差也为负。

因此N3-P2/P3/P4失败，出口为N3-E3。该结果排除了“静态未来可覆盖性损失
可以直接升级为稳定策略外部性”的当前机制命题。项目不设计FCRC-PPO、
FCRC shield或GNN近似器，也不追加同分布样本。

下一创新入口必须重新定义规范性控制对象，并与下列已失败路线保持清晰差异：

- 实现回报/累计成本的动作后分解；
- 通用弹药机会成本oracle；
- 静态一次覆盖匹配外部性；
- 仅靠辅助loss、mask阈值或图编码包装旧标签。
