# 第一创新 Claim–Evidence 矩阵

更新时间：2026-07-23  
状态：R2独立确认后冻结  
贡献类型：动态掩码序列资源分配中的成本测量、反事实信用与可辨识性边界

## 1. 核心主张

冻结后的第一创新主张为：

> 在AirDefense v1冻结factorized PPO的动态掩码序列分配中，同一步与未来
> 动作替代会系统性偏置回合累计资源成本对当前动作的局部信用读出；该机制
> 可跨新策略种子复现，但改变标签符号的强度受场景和资源类型约束。

该主张不等价于提出了新的PPO算法，也不声称已经解决all-noop、过度交战
或跨规模泛化。

## 4. 允许写入论文

1. 回合累计资源成本差不是当前动作局部资源信用的无偏读出；
2. 无冲突序列动作会同时产生同一步后缀替代和未来策略替代；
3. 共同随机数N/E成本账本可以精确分离这些组成；
4. 动作替代跨独立策略种子复现；
5. 符号失真的强度具有场景和资源类型边界。

## 5. 禁止表述

- “提出一种已经稳定优于PPO的新算法”；
- “解决了all-noop塌缩”；
- “机会成本oracle跨场景有效”；
- “动作替代对所有资源类型同样改变成本标签”；
- “GNN能够解决当前信用分配问题”；
- “首次发现”或任何未经系统文献检索支持的优先权主张。
