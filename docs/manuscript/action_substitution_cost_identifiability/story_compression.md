# W1-03 故事压缩冻结

更新时间：2026-07-24  
稿件定位：L2，较大方法论文中的测量、诊断与资源信用分解模块  
适用范围：AirDefense v1 冻结 factorized PPO 的反事实评估

## 1. 一句话版本

在 AirDefense v1 冻结 factorized PPO 的动态掩码序列分配中，回合成本混合
当前直接消耗与同一步、未来动作替代；三分量配对反事实账本可精确分离这种
混合并在新策略种子上复现其存在，但成本符号是否被掩盖取决于场景和资源类型，
该结果是测量诊断而非已验证的在线算法改进。

## 2. 三句话版本

**Problem：** 在 AirDefense v1 冻结 factorized PPO 的动态合法动作掩码和
自回归联合分配下，当前交战会改变同一步后缀及未来策略动作，因此回合累计
资源成本不是当前动作局部资源信用的纯读出。  

**Method：** 我们以 no-engage/engage（N/E）配对反事实轨迹、共同随机数和
逐时刻成本账本，将回合成本差精确分解为探针直接成本、同一步其他单元替代、
未来探针替代和未来其他单元替代。  

**Insight：** 该结构性替代在三个新策略种子上复现，但其是否足以改变累计成本
标签符号受场景和资源类型约束；增加 rollout 只能降低配对差的采样方差，不能
把该测量贡献解释为已稳定提升 PPO 的在线算法。

## 3. 一段话版本

动态掩码自回归联合动作使局部资源信用具有一个容易被回合指标隐藏的测量问题：
当前单元从 no-op 改为交战后，不仅产生正的直接资源成本，还会改变同一步后缀
单元的合法动作及未来冻结策略的行动序列。为分离这些分量，我们在 AirDefense v1
冻结 factorized PPO 下构造 N/E 共同随机数配对轨迹，并将
\(\Delta C_{\mathrm{episode}}\) 分解为
\(C_{\mathrm{direct}}\) 减去同一步其他单元、未来探针和未来其他单元三类替代成本。
修正后 7,776 条目标成本账本的最大恒等式误差为
\(8.88\times10^{-16}\)；9 个新来源模型、108 个与旧正式数据零 hash 重叠的
上下文进一步显示，seeds 17/18/19 的 time/resource 块级替代射击下界均为正。
然而，time/resource 中成本符号掩盖只覆盖 missile 的 2/9 个上下文和 laser 的
5/9 个上下文，资源恢复的通用安全机会价值与在线 BPCE/MCH-PPO 改进也未通过
门控。因此，本文把该成果限定为面向动态掩码序列资源分配的成本测量与可辨识性
模块，而不主张通用反事实信用算法或稳定 PPO 性能提升。

## 5. 用词边界

- 正文沿用 W1-01 冻结术语“动作替代”；可用“由后续动作介导”解释机制，
  但不在 W1-03 直接采用尚未审批的新规范术语。
- “精确”只修饰逐账本代数恒等式，不修饰统计估计或跨环境泛化。
- “独立确认”只表示新来源模型、上下文和旧 hash 零重叠，不表示分布外泛化。
- “支持”用于 C1-C3；C4-C6 必须使用“未支持普遍性/未通过门控”。
- 不使用“首次”“通用解决”“稳定优于 PPO”或“GNN 可修复”。
