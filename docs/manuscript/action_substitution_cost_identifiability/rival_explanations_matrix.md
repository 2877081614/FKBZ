# W1-07 竞争解释矩阵

更新时间：2026-07-28  
用途：区分已降低风险、仍保留边界和无法由当前设计排除的解释

## 1. 判定等级

| 等级 | 含义 |
| --- | --- |
| 较强排除 | 当前设计直接针对该解释，且独立门控给出一致证据 |
| 部分降低 | 当前证据削弱该解释，但仍有未操纵条件 |
| 保留 | 与当前结果相容，必须作为条件解释或限制 |
| 无法排除 | 当前设计没有相应干预，不得用修辞否定 |

## 2. 逐项审计

| ID | 竞争解释 | 当前证据 | 当前判定 | 能说什么 | 不能说什么 | 正文去向 |
| --- | --- | --- | --- | --- | --- | --- |
| RX01 | 结果只是随机 rollout 方差 | N/E 使用 CRN；R2 每 context 32 repeats；三个新 seed block 下界均为正；Actor 冻结 | 部分降低 | 在冻结协议的 `time_pressure/resource` 中，正替代不依赖单个随机 rollout | 已排除所有 Monte Carlo 偏差或任意 seed 波动 | D01、L02 |
| RX02 | 结果只是 all-noop 或某个异常来源模型副作用 | R2 9/9 模型无行为筛选保留；三个新 seed 均出现正 block 下界 | 部分降低 | 结果不依赖事后挑选单一优势模型 | 已排除来源策略质量、训练不足或所有策略病理 | D00、L04 |
| RX03 | 只是 laser 直接成本较低 | missile/laser 均有正 \(Sub_{\mathrm{shot}}\)；掩盖强度和 \(\rho_{\mathrm{sub}}\) 分层不同；P-C3 失败 | 保留为条件解释 | 较低直接成本更易被替代抵消，与当前分层结果一致 | 差异唯一由成本造成；missile 没有动作替代 | D04、L01 |
| RX04 | 只是固定单元执行顺序造成 | 同一步后缀项由动态前缀占用直接触发；只审计 order 0-1-2 | 无法排除 | 顺序是当前同一步替代机制的组成条件 | 对任意顺序鲁棒；顺序与资源类型效应已分离 | D03、L02、L04 |
| RX05 | 只是目标冲突处理造成 | 无冲突自回归后缀使已占用目标从后续合法集移除；未比较其他冲突机制 | 无法排除 | 结果依赖当前合法动作与冲突处理结构 | 在无冲突约束之外仍同强度成立 | D03、L02 |
| RX06 | 只是 AirDefense v1 成本定义特例 | 两种成本尺度和三个内部场景给出条件边界；没有第二环境 | 保留 | 账本在当前物理资源成本定义下可复核 | 任意奖励成本、预算或真实防空资源均适用 | D04、L01、L03 |
| RX07 | CRN 人为制造了动作相关性 | 两分支只共享外生随机带索引；状态、掩码和动作可分叉；目标按条件概率边缘化；CRN 理论角色是方差缩减（E15） | 较强排除其“定义结构分量”的解释 | CRN 对齐外生随机输入，没有定义替代项；动作分叉来自策略和环境转移 | CRN 证明全部因果路径可辨识；任意随机带实现都无误 | D01、D02e、L02 |
| RX08 | 目标抽样偶然性制造差异 | \(E\) 对全部合法目标按条件概率精确边缘化，概率和误差为零 | 较强排除 | 当前目标选择没有 Monte Carlo 抽样误差 | 目标表示、概率模型或合法集定义没有建模误差 | D02e、L02 |
| RX09 | 有利 context 被事后挑选 | context 槽位、配额和旧 hash 排除在 N/E 结果前冻结；R2 主确认切片和门槛预定 | 部分降低 | 不能按绘图或结果删选 context，主切片有预定角色 | context 分布代表所有可访问状态或真实任务频率 | D00、L01 |
| RX10 | 账本闭合只是公式自证，不能说明科学问题 | future-only 公式在同一账本出现系统残差；扩展项定位到同一步后缀动作；R1/R2 均观察到非正累计差与正替代并存 | 部分降低 | 恒等式与独立机制证据共同支持测量混合 | 代数闭合本身证明统计无偏、因果完备或算法增益 | D00、D03、L02 |

## 3. 写作决策

1. RX07 和 RX08 可较强回应，但仍限制在当前实现正确性和定义范围内；
2. RX01、RX02、RX09、RX10 只写“降低风险”或“与单一解释不一致”；
3. RX03 保留为资源条件解释，不能升级为唯一机制；
4. RX04-RX06 进入 Limitations，不声称已经排除；
5. 任何后续实验若改变顺序、冲突机制、成本定义或环境，必须重新审计 N/E
   分支合法性和三分量恒等式。
