# W1-02 创新演化记录

更新时间：2026-07-24  
目的：记录主张如何被实验和文献逐步收窄，避免将失败路线重新包装为优先权

## 1. 演化时间线

| 阶段 | 候选创新 | 关键结果 | 处理 |
| --- | --- | --- | --- |
| V0 | Maskable PPO 可直接解决大动作空间和冲突 | 能训练，但存在 all-noop、高成本交战和跨种子分叉 | 作为基线与问题来源，不是创新 |
| V1 | MCH-PPO/BPCE 通过分层反事实信用稳定改进 PPO | 多轮短训练未通过稳定性门控 | 在线算法主张否决 |
| V2 | 弹药机会成本标签可训练通用资源价值 | 标签在场景、种子和资源类型间不稳定 | 通用机会成本 oracle 否决 |
| V3 | 动作替代解释回合成本与局部动作成本不一致 | R1 发现替代，R2 在新策略种子上独立确认 | 转向测量和可辨识性贡献 |
| V4 | 同一步和未来替代可由成本账本精确拆分 | 7,776 条账本最大残差 `8.88e-16` | 形成核心方法证据 |
| V5 | 成本符号掩盖跨资源普遍成立 | missile 未达到预注册门槛，laser 达到 | 普遍性主张否决，保留条件边界 |
| V6 | 可按独立新型反事实信用算法论文定位 | 系统检索发现 CCA、因果效应分解、CAPO 等直接先例 | 定位收窄为 L2 方法论文组成部分 |

## 2. 文献检索前后的主张变化

### 检索前

> 动作替代可能是一种新的强化学习信用分配机制，可用于构造 MCH-PPO/BPCE。

问题：

- 把“机制存在”“测量可分解”和“在线算法有效”混成一个主张；
- 未区分已知反事实信用问题与当前操作化差异；
- `action substitution` 存在术语碰撞；
- 没有充分承认资源类型失败边界。

### 检索后

> 在动态掩码自回归资源分配中，已知的后续行为介导信用问题表现为可精确记账的
> 资源成本混合；当前贡献是三分量操作账本、独立机制确认和条件化符号边界，
> 不是已经验证的通用在线 PPO 改进。

变化：

- 从“提出一般问题”收窄为“在特定测量对象上操作化已知问题”；
- 从“完整新算法”收窄为“较大方法论文的测量与诊断模块”；
- 从“普遍符号失真”收窄为“场景/资源类型条件化”；
- 从 `action substitution` 优先权表述转向“后续动作介导的成本替代”术语建议。

## 4. 当前创新核

当前可守住的创新核由三部分组成：

1. **测量对象**：动态掩码自回归资源分配中的局部资源成本，而非一般团队回报；
2. **操作方法**：N/E 配对 CRN 下的同一步后缀、未来探针和未来其他单元三分量账本；
3. **经验洞见**：结构性替代跨新策略种子复现，但符号掩盖受场景和资源类型约束。

其中第 1 点是对已知问题的领域化和形式化，第 2-3 点构成当前实质差异。

## 5. 当前不属于创新核

- factorized joint PPO；
- invalid action masking；
- 自回归联合动作本身；
- CRN 本身；
- all-noop 现象；
- MCH-PPO/BPCE 的失败变体；
- 通用弹药机会成本 oracle；
- 未实现或未验证的 GNN 修复；
- “实验量大”或“防空环境不同”。

## 6. 后续演化规则

1. W1 写作按 L2 执行，不以措辞把定位重新抬回 L1；
2. 若后续形成在线算法，必须另立估计量、理论或训练门控，不从当前诊断结果自动推导；
3. 若采用“后续动作介导的成本替代”，须更新术语账本、公式说明和冲突日志；
4. 新论文必须分别报告正证据、否决主张和适用边界；
5. GNN 仍可作为第二研究方向，但不能被写成当前测量问题的已验证解法。

## 7. 当前版本结论

创新并未消失，而是从“泛化过度的 PPO 算法创新”收敛为“有严格账本、独立确认和
失败边界的资源信用测量贡献”。系统查新表明它适合成为更大方法论文的重要组成部分，
而不是在当前证据下独立承担通用反事实信用算法的优先权。
