# W1-02 最近工作四层比较

更新时间：2026-07-24  
比较维度：Problem、Method、Evidence、Insight

## 1. 当前工作的四层定义

| 层 | 当前冻结内容 |
| --- | --- |
| Problem | 动态掩码自回归分配中，回合累计资源成本混合当前动作直接成本与后续动作介导的成本变化，可能掩盖局部成本符号 |
| Method | 冻结策略下，以 N/E 配对、共同随机数和目标条件精确边缘化构造三分量成本账本 |
| Evidence | 新策略种子上的 7,776 条目标成本账本满足数值恒等式；替代存在，但符号掩盖受场景和资源类型约束 |
| Insight | 增加 rollout 只能降低采样噪声，不能解除“局部直接成本”和“下游行为介导成本”在回合标签中的结构混合 |

## 3. 三项压力测试

### 3.1 是否已有等价问题

**部分有。** CCA 已明确把“后续动作”列为需要从当前动作信用中分离的因素；
Castellini et al. 已指出未来历史依赖当前动作会使差分回报基线失去一般无偏性；
2024-2025 年的因果工作已直接分解经其他智能体行为传播的动作效应。

因此不能把“后续动作污染当前动作信用”写成新的普遍问题。

### 3.2 是否已有等价方法

**未发现完全等价方法，但相邻方法距离很近。**

既有方法已经覆盖反事实默认动作、未来条件基线、行为介导效应和顺序团队信用。
当前保留下来的方法差异是以下组合：

1. 当前干预改变同一步后缀单元的动态合法动作集；
2. 将同一步后缀、未来探针和未来其他单元的资源成本分别记账；
3. 满足
   \(\Delta C_{\mathrm{episode}}=C_{\mathrm{direct}}-Sub_{\mathrm{cost,total}}\)
   的逐账本恒等式；
4. 使用 N/E 配对 CRN 减少方差，但不把 CRN 宣称为可辨识性来源；
5. 把成本符号掩盖限定到具体场景和资源类型。

这是一种特定测量对象的操作化分解，不是一般因果效应分解的替代品。

### 3.3 是否只是 AirDefense 证据不同

**不是，但差异不足以支持 L1。**

如果只有防空场景和更多种子，应该判为 L3。当前仍高于 L3 的原因是：

- 测量对象从一般回报贡献收窄为有直接物理含义的资源成本；
- 同一步动态掩码后缀被单独列为一条介导路径；
- 三分量账本能逐行验证代数恒等式；
- 实验给出了“存在替代”和“符号掩盖并不普遍”两个可否证边界。

这些是 Method 与 Insight 层差异，而不只是换了环境。

## 4. 风险排序

| 排名 | 最近工作 | 主要威胁 | 应对 |
| ---: | --- | --- | --- |
| 1 | Counterfactual Effect Decomposition (2025) | 已覆盖后续智能体行为介导的因果效应 | 明确只主张动态掩码资源成本操作账本与边界证据 |
| 2 | CAPO (2026) | 已进入固定顺序协作团队的算法信用分配 | 不主张一般顺序信用算法；将当前成果定位为诊断/测量模块 |
| 3 | Castellini et al. (2022) | 已指出未来动作依赖造成差分回报偏差 | 强调精确三分量账本、同一步后缀和符号边界 |
| 4 | CCA (2021) | 已明确分离后续动作和外部因素 | 区分低方差 PG 与资源成本路径测量 |
| 5 | Agent-Specific Effects (2024) | 已定义经其他智能体响应传播的效应 | 避免一般因果“首创”表述 |

## 5. 比较结论

最近工作没有同时覆盖“动态合法动作掩码、自回归同一步后缀、三类资源成本账本、
逐行恒等式、成本符号掩盖及资源类型边界”。但其 Problem 和一般因果 Method 已有强先例，
故当前工作不能按独立通用算法创新定位。唯一合理门禁判定为 **L2**。
