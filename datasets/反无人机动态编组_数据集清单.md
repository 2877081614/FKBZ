# 反无人机动态编组实验数据集清单

整理日期：2026-07-01

本文档用于支撑“反无人机动态编组”后续实验的数据准备。数据来源优先选择公开 benchmark、官方项目页、论文配套仓库、成熟仿真器和权威数据托管平台。由于反无人机动态编组本身很少存在端到端公开数据集，建议采用“真实感知数据 + 轨迹/威胁建模数据 + 仿真训练环境”的组合路线。

## 1. 数据集使用策略

反无人机动态编组实验建议拆成三层数据需求：

1. 感知层数据：用于训练或验证无人机目标检测、跟踪、热红外识别、RF/声学识别模型。
2. 态势层数据：用于构建目标轨迹、速度、航向、威胁等级、突防时间等状态变量。
3. 决策层环境：用于训练 MADDPG、MAPPO、QMIX、图注意力 MARL、分层 MARL 等动态编组算法。

因此，后续实验不应只依赖单一数据集，而应将真实数据用于校准仿真参数，将仿真环境用于大规模策略训练，再用真实数据或半真实回放场景进行验证。

## 3. 真实感知与识别数据集

### 3.1 Anti-UAV / Anti-UAV410

来源：

- 官方主页：[Anti-UAV Challenge](https://anti-uav.github.io/)
- 官方/相关仓库：[Anti-UAV GitHub](https://github.com/ucas-vg/Anti-UAV)

数据类型：

- 可见光与红外视频。
- 无人机目标检测、单目标跟踪、长时跟踪。
- 包含无人机尺度变化、遮挡、背景干扰、目标消失再出现等情况。

适合支撑的实验：

- 反无人机视觉跟踪模块。
- 红外/可见光目标检测与跟踪鲁棒性测试。
- 动态编组仿真中的目标轨迹回放。
- 小目标、弱纹理、复杂背景下的目标状态估计。

对本课题的价值：

Anti-UAV 系列是最贴近“反无人机”语义的数据来源之一。后续可以从视频中提取无人机位置、速度、尺度、遮挡状态，作为仿真环境中的真实轨迹模板或感知误差模型。

建议使用方式：

- 先用于训练/测试目标检测与跟踪模型。
- 再将跟踪输出转换为动态编组环境中的目标轨迹。
- 可构建“真实视频回放 + MARL 决策”的半实物仿真流程。

### 3.2 HIT-UAV

来源：

- 数据集论文/项目页常见入口：[HIT-UAV dataset search page](https://github.com/suojiashun/HIT-UAV-Infrared-Thermal-Dataset)

数据类型：

- 红外热成像航拍数据。
- 包含无人机视角下的多类目标检测标注。
- 适合低光照、夜间、热红外目标感知研究。

适合支撑的实验：

- 红外探测模型训练。
- 低光照或夜间防御场景中的目标检测。
- 传感器异构输入建模。

对本课题的价值：

反无人机系统通常需要昼夜工作，红外数据对夜间态势构建有重要意义。HIT-UAV 可用于训练红外检测模型，也可用于估计热红外目标检测误差，并将误差注入动态编组仿真。

### 3.3 DroneRF

来源：

- Mendeley Data 检索入口：[DroneRF dataset on Mendeley Data](https://data.mendeley.com/)
- 论文常用名称：DroneRF dataset / RF-based drone detection and identification dataset。

数据类型：

- 无人机遥控链路或通信链路 RF 信号。
- 通常用于无人机存在检测、型号识别、飞行模式识别等任务。

适合支撑的实验：

- 非视觉无人机探测。
- 视觉受限情况下的早期预警。
- 多模态态势输入：视觉 + RF。
- 通信受限或电子对抗场景建模。

对本课题的价值：

动态编组不仅依赖视觉目标位置，还可以依赖 RF 探测提供的“目标存在、型号、活动模式、控制链路强度”等先验信息。DroneRF 可用于训练 RF 分类器，也可用于构建仿真中的传感器置信度模型。

注意事项：

- DroneRF 的具体下载入口可能在 Mendeley Data 或作者维护页面中变化，后续下载时应核对论文 DOI 和数据版本。
- RF 数据与具体硬件和采样率相关，跨场景泛化需要谨慎。

### 3.4 RFUAV

来源：

- 官方仓库：[RFUAV GitHub](https://github.com/kitoweeknd/RFUAV)

数据类型：

- 无人机 RF 信号数据。
- 用于无人机识别、分类和无线电特征分析。

适合支撑的实验：

- RF 探测基线。
- 多模态反无人机场景中的非视觉传感器输入。
- 无人机类型识别与威胁等级先验估计。

对本课题的价值：

RFUAV 可以作为 DroneRF 的补充数据源，用于验证 RF 模型在不同数据来源上的稳定性。若后续研究通信受限或电子干扰编组，RF 数据尤其有价值。

### 3.5 MMAUD

来源：

- 官方仓库：[MMAUD: Multi-Modal Anti-UAV Dataset](https://github.com/ntu-aris/MMAUD)

数据类型：

- 多模态反无人机数据。
- 通常面向无人机检测、识别和多模态融合。

适合支撑的实验：

- 声学/视觉/多模态无人机检测。
- 弱视觉条件下的目标发现。
- 多传感器融合态势估计。

对本课题的价值：

MMAUD 可用于构建“多传感器防御节点”的观测模型。例如，某些防御单元只有声学/RF 早期告警，另一些单元具有可见光/红外精确跟踪能力。该设定可支撑异构资源动态编组研究。

### 3.6 VisDrone

来源：

- 官方仓库：[VisDrone Dataset](https://github.com/VisDrone/VisDrone-Dataset)
- 官方页面：[VisDrone Challenge](https://aiskyeye.com/)

数据类型：

- 大规模无人机平台采集的图像与视频。
- 任务包括目标检测、视频目标检测、单目标跟踪、多目标跟踪等。

适合支撑的实验：

- 小目标检测模型预训练。
- 多目标跟踪算法验证。
- 航拍视角下的密集目标检测。

对本课题的价值：

VisDrone 中的目标多为地面行人和车辆，不是来袭无人机，因此不能直接作为反无人机目标数据。但它非常适合训练航拍小目标检测和多目标跟踪模型，也可用于构建感知模块的基础能力。

### 3.7 UAVDT

来源：

- 官方/论文页面常见入口：[UAVDT Dataset](https://sites.google.com/view/grli-uavdt/)

数据类型：

- 无人机平台拍摄的车辆检测与跟踪视频。
- 包含不同视角、遮挡、天气和目标尺度变化。

适合支撑的实验：

- 多目标检测与跟踪基线。
- 目标轨迹提取。
- 航拍视角下的检测难度建模。

对本课题的价值：

UAVDT 与 VisDrone 类似，更适合作为感知算法预训练和轨迹建模参考，而不是直接作为反无人机来袭目标数据。

### 3.8 Drone-vs-Bird

来源：

- 挑战赛/项目入口可从：[Drone-vs-Bird Detection Challenge](https://wosdetc2021.wordpress.com/drone-vs-bird-detection-challenge/) 检索。

数据类型：

- 无人机和鸟类视频/图像。
- 关注无人机与鸟类的区分。

适合支撑的实验：

- 反无人机视觉误警控制。
- 鸟类干扰场景下的目标识别。
- 小目标分类模型验证。

对本课题的价值：

在真实部署中，鸟类是反无人机视觉系统的重要误警来源。该数据集可用于训练或评估“无人机/非无人机”分类器，并将误警率作为动态编组系统的输入不确定性。

## 4. 轨迹、群体运动与态势建模数据

### 4.1 Stanford Drone Dataset

来源：

- 官方页面：[Stanford Drone Dataset](https://cvgl.stanford.edu/projects/uav_data/)

数据类型：

- 无人机俯视视角下的行人、自行车、车辆等多智能体轨迹。
- 包含真实场景中的群体运动、避让和交互行为。

适合支撑的实验：

- 群体轨迹预测。
- 多目标运动模型校准。
- 蜂群行为或密集目标运动的参考建模。

对本课题的价值：

该数据集不是无人机蜂群数据，但它提供了真实多目标轨迹，可用于学习或校准多目标运动模型。若后续要构建复杂来袭无人机队形、避让、分散和聚合行为，可以把该数据集作为群体运动建模参考。

### 4.2 真实反无人机视频轨迹提取

来源：

- Anti-UAV / Anti-UAV410。
- Drone-vs-Bird。
- 其他公开无人机跟踪视频。

数据类型：

- 从真实视频中提取目标中心点、边界框、尺度变化和可见性状态。

适合支撑的实验：

- 仿真环境中的真实轨迹回放。
- 目标速度与机动模型校准。
- 探测丢失、遮挡、误检和漏检模型构建。

建议处理流程：

1. 使用标注框计算目标中心点。
2. 将像素坐标归一化到仿真平面或视场坐标。
3. 用 Kalman filter 或 spline 平滑轨迹。
4. 估计速度、加速度、目标可见性和遮挡状态。
5. 将轨迹导出为 MARL 环境可读取的 episode 文件。

## 5. 仿真与训练环境

### 5.1 AirSim

来源：

- 官方仓库：[Microsoft AirSim](https://github.com/microsoft/AirSim)

类型：

- 高保真无人机/车辆仿真器。
- 支持 Unreal Engine 场景、相机、深度、分割、IMU、GPS 等传感器。

适合支撑的实验：

- 构建可视化反无人机场景。
- 生成可见光、深度、分割等合成数据。
- 训练或验证无人机探测与追踪模型。
- 作为真实感仿真平台验证编组策略。

对本课题的价值：

AirSim 适合构建视觉真实感较强的实验场景。后续可用它生成“来袭无人机 + 防御传感器 + 保护目标”的数据，用于感知模块训练和策略验证。

限制：

- 直接用于大规模 MARL 训练可能效率较低。
- 需要额外开发反无人机任务逻辑、奖励函数和多智能体接口。

### 5.2 gym-pybullet-drones

来源：

- 官方仓库：[gym-pybullet-drones](https://github.com/utiasDSL/gym-pybullet-drones)

类型：

- 基于 PyBullet 的无人机强化学习环境。
- 支持单机和多机控制任务。

适合支撑的实验：

- 快速搭建多无人机仿真。
- 强化学习策略训练。
- 多智能体控制算法验证。
- 低成本测试编组、避障、跟踪、围捕等机制。

对本课题的价值：

该环境比 AirSim 更轻量，更适合训练阶段使用。可以将其改造为“防御资源节点 + 来袭无人机目标”的简化动力学环境，用于 MADDPG、MAPPO、QMIX 和 GNN-MARL 的算法验证。

### 5.3 Flightmare

来源：

- 官方仓库：[Flightmare](https://github.com/uzh-rpg/flightmare)
- 项目页面：[Flightmare project](https://rpg.ifi.uzh.ch/flightmare.html)

类型：

- 面向无人机自主飞行的高效仿真环境。
- 支持视觉渲染和强化学习训练。

适合支撑的实验：

- 高速飞行仿真。
- 视觉-控制联合训练。
- 复杂场景下无人机机动行为建模。

对本课题的价值：

Flightmare 可用于构建更高动态的无人机运动和追踪场景。如果研究重点涉及高速目标、机动突防或视觉闭环决策，可以作为 AirSim 和 PyBullet 之间的折中选择。

### 5.4 PettingZoo MPE

来源：

- 官方文档：[PettingZoo](https://pettingzoo.farama.org/)
- MPE 环境说明：[PettingZoo MPE](https://pettingzoo.farama.org/environments/mpe/)

类型：

- 多智能体强化学习标准接口和基准环境。
- 包含 simple_spread、simple_tag、simple_adversary 等经典多智能体任务。

适合支撑的实验：

- MARL 算法调试。
- MADDPG、MAPPO、QMIX 接口验证。
- 注意力 critic、图编码器、角色模块的快速原型测试。

对本课题的价值：

PettingZoo MPE 不直接是反无人机场景，但非常适合先验证算法模块是否有效。建议先在 MPE 上调通多智能体训练框架，再迁移到自定义反无人机动态编组环境。

### 5.5 VMAS

来源：

- 官方仓库：[VMAS](https://github.com/proroklab/VectorizedMultiAgentSimulator)
- 官方文档：[VMAS documentation](https://vmas.readthedocs.io/)

类型：

- 向量化多智能体仿真器。
- 支持 GPU/批量环境并行，适合大规模 MARL 训练。

适合支撑的实验：

- 大批量 MARL 训练。
- 自定义二维连续空间反无人机场景。
- 多智能体任务分配、围堵、覆盖、保护目标等任务。

对本课题的价值：

如果后续重点是算法训练效率和大规模消融实验，VMAS 很适合作为核心仿真后端。可以在二维平面中快速构建防御资源、无人机目标、保护区域、传感器覆盖和拦截约束。

## 6. 建议的数据组合方案

### 方案 A：视觉反无人机动态编组

适合研究方向：

- 图注意力增强动态编组。
- 可变规模无人机威胁泛化。
- 真实轨迹回放与仿真训练结合。

数据组合：

- Anti-UAV / Anti-UAV410：真实无人机跟踪。
- HIT-UAV：红外检测。
- AirSim：合成视觉场景。
- VMAS 或 gym-pybullet-drones：MARL 训练。

实验链路：

1. 用 Anti-UAV / HIT-UAV 训练或评估目标检测与跟踪模型。
2. 从真实数据中提取目标轨迹和检测误差。
3. 在 VMAS/gym-pybullet-drones 中构建动态编组环境。
4. 用真实轨迹参数校准仿真。
5. 训练图注意力 MARL 策略。

### 方案 B：多模态反无人机动态编组

适合研究方向：

- 异构资源协同编组。
- 通信受限条件下的分布式编组。
- 威胁优先级驱动的目标分配。

数据组合：

- Anti-UAV：视觉/红外跟踪。
- DroneRF 或 RFUAV：RF 探测。
- MMAUD：多模态检测。
- AirSim 或自定义 VMAS：多传感器仿真。

实验链路：

1. 分别构建视觉、红外、RF、声学观测模型。
2. 估计不同传感器的探测概率、误警率和延迟。
3. 在仿真环境中为不同防御节点赋予不同传感器能力。
4. 训练异构多智能体动态编组策略。
5. 对比单模态策略和多模态策略。

### 方案 C：纯决策与算法验证

适合研究方向：

- 分层 MARL。
- 角色自适应编组。
- 稀疏奖励探索增强。
- 安全约束和风险敏感强化学习。

数据组合：

- PettingZoo MPE：算法原型验证。
- VMAS：高效自定义 MARL 训练。
- gym-pybullet-drones：加入无人机动力学。
- Anti-UAV 轨迹：用于半真实测试。

实验链路：

1. 在 PettingZoo MPE 中验证算法模块。
2. 在 VMAS 中构建二维反无人机编组环境。
3. 在 gym-pybullet-drones 中加入更真实的动力学约束。
4. 用 Anti-UAV 真实轨迹进行回放测试。
